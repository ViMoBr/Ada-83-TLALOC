GET_STATIC_VALUE, le pliage d'INTEGER'LAST et la relecture de _STANDRD
sont donc HORS DE CAUSE pour ce site. Le menteur est l'un des opérateurs
de comparaison UARITH à retour BOOLEAN (">=" ou "<=", ceux commentés
"FOR COMPILER RANGE TESTS") — tel que compilé par T1 dans le binaire T2.
Le chemin d'erreur exige que les trois étages aient répondu faux ; or au
moins deux réponses sont fausses mathématiquement :
    UPPER_BOUND <= INTEGER_LAST        (cas d'ÉGALITÉ, 3 doublets)
    UPPER_BOUND <= LONG_INTEGER_LAST   (cas STRICT, longueurs 3 vs 5)
D2 imprime les six booléens pour savoir LEQUEL (ou lesquels) ment, et
dans quelle configuration (égalité / longueurs différentes / signe).

Grille de lecture (URADIX = 10_000 ; 2147483647 = [21][4748][3647],
3 doublets ; LONG_INTEGER'LAST = 5 doublets) :

  GE_I  = FALSE  -> ">=" ment sur 0 vs négatif long : voie du SIGNE
                    (champ S du VECTOR mal lu/écrit).
  LE_I  = FALSE  -> "<=" ment sur ÉGALITÉ à 3 doublets : voie
                    V_EQUAL / boucle de chiffres de V_LESS.
  LE_LI = FALSE  -> "<=" ment sur STRICTEMENT-INFÉRIEUR à longueurs
                    différentes (3 vs 5) : voie du champ L
                    (comparaison de longueurs de V_LESS).
  LE_SI attendu FALSE (légitime : 3 doublets vs 1). GE_SI, GE_LI
  attendus TRUE. Tout écart supplémentaire élargit le périmètre.

Chacune de ces trois voies pointe une PARTIE différente du record
VECTOR packé (S, chiffres, L) — exactement le "désaccord des deux
parties" laissé ouvert au piège n°143. PACKV_TEST (vert) couvrait
écriture/lecture indexée et copies ; il ne couvrait PAS la LECTURE de
composantes scalaires S et L d'un record contenant un tableau packé
dans un contexte de comparaison. D2 dira laquelle instrumenter.
