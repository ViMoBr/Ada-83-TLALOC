DIAGNOSTIC A — les 3 ÉCHECS de S1 (et S3, mort avant d'y arriver)
--------------------------------------------------------------------------------
Le FINC tranche.  `Y := DR( X )` émet :
	LVA 2, Y_disp / La / LI _DR.size / LVA 1, X_disp / BLKMOV
La source du BLKMOV est l'@DOUBLET de X (LVA X_disp) SANS le `La` de
dépliage — comparez l'égalité `Z = X` trois lignes plus bas, qui porte ses
deux `La , 0`.  BLKMOV copiait donc le doublet lui-même (pointeurs) dans Y :
champs faux, tests 1-3 ÉCHEC.  Même trou dans S3 (`W := DVEC(V)` : LVA
V_disp nu).  Cause : les deux branches d'affectation passent déjà par la
règle unique CODE_COMPOSITE_DATA_ADDRESS, mais sa liste de producteurs
d'@doublet est { USED_OBJECT_ID, FUNCTION_CALL, QUALIFIED } — la CONVERSION en est absente.  Or la
conversion composite est une IDENTITÉ (C1) : elle est TRANSPARENTE pour la
forme du résultat.  La classer elle-même serait faux (conversion d'un
indexé laisse @data) : il faut classer son OPÉRANDE, en dépouillant les
conversions — exactement comme RECURSE_SELECTED normalise la
conversion-vue (n° 120b), et même motif que l'amendement n° 112
(producteur d'@doublet absent de la règle).  UNE modification, les deux
branches (record ET tableau) guéries.

DIAGNOSTIC B — le segfault dans MK_L18
--------------------------------------------------------------------------------
Votre lecture est la bonne.  Protocole des fonctions à résultat record :
le paramètre `result__ofs` porte l'@doublet du lieu résultat ; le corps le
DÉRÉFÉRENCE (`La 2,-result__ofs ; La , 0`) puis bâtit l'agrégat, et le RTD
prm_siz-8 laisse ce même @doublet en sommet pour l'appelant (son `La , 0`
final le déplie).  Le CORPS de MK est donc CONFORME.  C'est l'APPELANT
(élaboration `S : SET := MK(7)`) qui pousse le placeholder `LI 0` comme
lieu résultat : MK déréférence 0 → votre `mov (%rax),%rax` avec rax=0.
C'est la restriction déjà au carnet pour les TABLEAUX contraints
(« le slot résultat prend vraisemblablement le placeholder LI 0 ») —
désormais PROUVÉE, étendue aux records, et munie d'une reproduction
minimale.  C'est un des segfaults SUSPENDUS (décision du 28/07) : on ne
l'ouvre pas en plein C1.  Le côté appelant d'INSTANCIATION (TO_CHN,
élucidé) est correct — c'est le modèle à copier le jour du chantier
(à fusionner avec C7/NOTE_MODELE).  Le témoin v1 est ARCHIVÉ comme témoin
futur de ce chantier ; le témoin v2 ci-joint passe par
`procedure MK( N : INTEGER; S : out SET )` — paramètre out record simple,
machinerie du quotidien du corpus — et ne change RIEN d'autre
(12 assertions, mêmes conversions, mêmes attendus).
