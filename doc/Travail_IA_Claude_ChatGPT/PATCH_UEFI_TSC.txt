PATCH codi_x86_64U.finc  --  palier 4bis : horloge RTC + TSC
Base : le fichier issu du palier 4 (SYS_CLOCK_GETTIME sur GetTime seul).

Motif : sous OVMF, EFI_TIME.Nanosecond est rendu NUL et la resolution de la RTC
est d'une seconde. SYS_CLOCK_GETTIME rendait donc tv_nsec = 0 et un tv_sec
quantifie a la seconde, alors que les trois autres cibles donnent la nanoseconde.
De plus GetTime est un service runtime qui lit la CMOS par ports d'E/S : des
dizaines de microsecondes par appel.

Principe retenu, le meme que toutes les horloges d'OS : la RTC donne l'ORIGINE,
une fois au demarrage, et le compteur de cycles du processeur donne la CADENCE.

Trois retouches.
  1. .bss  : frequence, ancre TSC, ancre epoque
  2. le bloc horloge : UEFI_STALL, UEFI_RDTSC, UEFI_EPOCH_NOW, UEFI_CLOCK_INIT,
     SYS_CLOCK_GETTIME. La conversion calendaire du palier 4 n'est pas jetee :
     elle est simplement deplacee dans UEFI_EPOCH_NOW, appelee une fois au
     demarrage au lieu d'une fois par appel.
  3. UEFI_ENTRY : appel de UEFI_CLOCK_INIT avant la chute dans le FAS

PATCH 1  --  .bss : etat de l'horloge

--- ANCRE (ne pas modifier, sert a se reperer) --------------------------------------------------------
UEFI_TIME:		rb 16					; EFI_TIME rendu par RuntimeServices->GetTime
--- BLOC A INSERER -----------------------------------------------------------------------------------

UEFI_TSC_ANCHOR:	rq 1					; TSC au moment de l'ancrage
UEFI_EPOCH_ANCHOR:	rq 1					; secondes Unix au moment de l'ancrage

PATCH 2  --  le bloc horloge
========================================================================================================
Tout le bloc du palier 4, commentaire d'en-tete compris, est remplace.
--- BLOC A SUPPRIMER ---------------------------------------------------------------------------------
;-----------------------------------------------------------------------
; SYS_CLOCK_GETTIME -- @timespec_buffer ->
;
; Lit l'horloge. Le parametre est depile : c'est l'adresse d'une zone de
; 16 octets (struct timespec : qword tv_sec, qword tv_nsec) remplie ici.
;
; Sous UEFI, RuntimeServices->GetTime ne rend PAS un compte d'epoque mais
; une date eclatee, EFI_TIME (16 octets) :
;	 +0  UINT16 Year		1900..9999
;	 +2  UINT8  Month		1..12
;	 +3  UINT8  Day		1..31
;	 +4  UINT8  Hour		0..23
;	 +5  UINT8  Minute	0..59
;	 +6  UINT8  Second	0..59
;	 +7  UINT8  Pad1
;	 +8  UINT32 Nanosecond	0..999999999
;	+12  INT16  TimeZone	-1440..1440, ou 2047 = non specifie
;	+14  UINT8  Daylight
;	+15  UINT8  Pad2
; La conversion en secondes depuis 1970-01-01 est donc a notre charge.
; C'est l'inverse exact du travail de la version Windows, qui recevait un
; FILETIME (compte de 100 ns depuis 1601) et n'avait qu'a translater.
;
; Algorithme : days_from_civil (Howard Hinnant). On decale l'annee pour
; faire commencer le calendrier en mars, ce qui met le 29 fevrier en fin
; d'annee et supprime toute exception : la longueur des cinq premiers mois
; suit alors exactement (153*mp + 2)/5, et le cycle gregorien de 400 ans
; vaut 146097 jours. Aucune table, aucun branchement sur les bissextiles.
;
; Fuseau : la spec UEFI pose Localtime = UTC - TimeZone (PST vaut 480).
; On ajoute donc TimeZone*60 pour revenir a UTC. Si TimeZone vaut 2047,
; le firmware ne sait pas ou il est : on prend la date telle quelle.
; OVMF sous QEMU rend 2047, donc ce chemin est le seul reellement exerce.
;-----------------------------------------------------------------------

;			-----------------
macro			SYS_CLOCK_GETTIME
;			-----------------
  local m_gt2, m_ok, tz_done
  POP_RSI								; RSI = @timespec_buffer (non volatil : survit a l'appel)

			; RuntimeServices->GetTime( &UEFI_TIME, NULL )
  db 0x4C, 0x8B, 0x15						; mov r10,[rip+UEFI_SYSTEM_TABLE]
  dd UEFI_SYSTEM_TABLE - ($ + 4)
  db 0x4D, 0x8B, 0x52, RuntimeServices				; mov r10,[r10+0x58]
  db 0x4D, 0x8B, 0x52, GetTime					; mov r10,[r10+0x18]	R10 = &GetTime
  db 0x48, 0x8D, 0x0D						; lea rcx,[rip+UEFI_TIME]
  dd UEFI_TIME - ($ + 4)
  db 0x31, 0xD2							; xor edx,edx		Capabilities = NULL
  db 0x48, 0x89, 0xE0						; mov rax,rsp
  db 0x48, 0x83, 0xE4, 0xF0						; and rsp,-16
  db 0x48, 0x83, 0xEC, 0x30						; sub rsp,48
  db 0x48, 0x89, 0x44, 0x24, 0x28					; mov [rsp+40],rax
  db 0x41, 0xFF, 0xD2						; call r10
  db 0x48, 0x8B, 0x64, 0x24, 0x28					; mov rsp,[rsp+40]

			; days_from_civil( Year, Month, Day )
  db 0x0F, 0xB7, 0x05						; movzx eax,word [rip+UEFI_TIME+0]	Year
  dd UEFI_TIME - ($ + 4)
  db 0x0F, 0xB6, 0x0D						; movzx ecx,byte [rip+UEFI_TIME+2]	Month
  dd UEFI_TIME + 2 - ($ + 4)
  db 0x44, 0x0F, 0xB6, 0x05						; movzx r8d,byte [rip+UEFI_TIME+3]	Day
  dd UEFI_TIME + 3 - ($ + 4)
  db 0x83, 0xF9, 0x02						; cmp ecx,2		mars debute l'annee
  db 0x77, m_gt2 - ($ + 1)						; ja m_gt2
  db 0xFF, 0xC8							; dec eax		y -= 1  (janvier, fevrier)
  db 0x83, 0xC1, 0x09						; add ecx,9		mp = m + 9
  db 0xEB, m_ok - ($ + 1)						; jmp m_ok
m_gt2:
  db 0x83, 0xE9, 0x03						; sub ecx,3		mp = m - 3
m_ok:
  db 0x31, 0xD2							; xor edx,edx
  db 0x41, 0xB9, 0x90, 0x01, 0x00, 0x00				; mov r9d,400
  db 0x41, 0xF7, 0xF1						; div r9d		EAX = era, EDX = yoe
  db 0x41, 0x89, 0xC2						; mov r10d,eax		era
  db 0x41, 0x89, 0xD3						; mov r11d,edx		yoe = annee dans le cycle de 400
  db 0x69, 0xC9, 0x99, 0x00, 0x00, 0x00				; imul ecx,ecx,153
  db 0x83, 0xC1, 0x02						; add ecx,2
  db 0x89, 0xC8							; mov eax,ecx
  db 0x31, 0xD2							; xor edx,edx
  db 0x41, 0xB9, 0x05, 0x00, 0x00, 0x00				; mov r9d,5
  db 0x41, 0xF7, 0xF1						; div r9d		(153*mp+2)/5
  db 0x44, 0x01, 0xC0						; add eax,r8d		+ jour
  db 0xFF, 0xC8							; dec eax
  db 0x41, 0x89, 0xC0						; mov r8d,eax		doy = jour dans l'annee decalee
  db 0x44, 0x89, 0xD8						; mov eax,r11d
  db 0x31, 0xD2							; xor edx,edx
  db 0x41, 0xB9, 0x64, 0x00, 0x00, 0x00				; mov r9d,100
  db 0x41, 0xF7, 0xF1						; div r9d
  db 0x41, 0x89, 0xC1						; mov r9d,eax		yoe/100 (siecles non bissextiles)
  db 0x44, 0x89, 0xD8						; mov eax,r11d
  db 0x69, 0xC0, 0x6D, 0x01, 0x00, 0x00				; imul eax,eax,365
  db 0x44, 0x89, 0xD9						; mov ecx,r11d
  db 0xC1, 0xE9, 0x02						; shr ecx,2		yoe/4
  db 0x01, 0xC8							; add eax,ecx
  db 0x44, 0x29, 0xC8						; sub eax,r9d
  db 0x44, 0x01, 0xC0						; add eax,r8d		doe = jour dans le cycle
  db 0x45, 0x69, 0xD2, 0xB1, 0x3A, 0x02, 0x00			; imul r10d,r10d,146097	jours par cycle
  db 0x44, 0x01, 0xD0						; add eax,r10d
  db 0x2D, 0x6C, 0xFA, 0x0A, 0x00					; sub eax,719468	origine -> 1970-01-01

			; secondes = jours*86400 + h*3600 + m*60 + s
  db 0x48, 0x63, 0xC0						; movsxd rax,eax
  db 0x48, 0x69, 0xC0, 0x80, 0x51, 0x01, 0x00			; imul rax,rax,86400
  db 0x0F, 0xB6, 0x0D						; movzx ecx,byte [rip+UEFI_TIME+4]	Hour
  dd UEFI_TIME + 4 - ($ + 4)
  db 0x69, 0xC9, 0x10, 0x0E, 0x00, 0x00				; imul ecx,ecx,3600
  db 0x48, 0x01, 0xC8						; add rax,rcx
  db 0x0F, 0xB6, 0x0D						; movzx ecx,byte [rip+UEFI_TIME+5]	Minute
  dd UEFI_TIME + 5 - ($ + 4)
  db 0x6B, 0xC9, 0x3C						; imul ecx,ecx,60
  db 0x48, 0x01, 0xC8						; add rax,rcx
  db 0x0F, 0xB6, 0x0D						; movzx ecx,byte [rip+UEFI_TIME+6]	Second
  dd UEFI_TIME + 6 - ($ + 4)
  db 0x48, 0x01, 0xC8						; add rax,rcx

			; UTC = heure locale + TimeZone  (spec : Localtime = UTC - TimeZone)
  db 0x0F, 0xBF, 0x0D						; movsx ecx,word [rip+UEFI_TIME+12]	TimeZone
  dd UEFI_TIME + 12 - ($ + 4)
  db 0x81, 0xF9, 0xFF, 0x07, 0x00, 0x00				; cmp ecx,EFI_UNSPECIFIED_TIMEZONE
  db 0x74, tz_done - ($ + 1)						; je tz_done		fuseau inconnu : on garde tel quel
  db 0x6B, 0xC9, 0x3C						; imul ecx,ecx,60
  db 0x48, 0x63, 0xC9						; movsxd rcx,ecx
  db 0x48, 0x01, 0xC8						; add rax,rcx
tz_done:
  db 0x48, 0x89, 0x06						; mov [rsi],rax		tv_sec
  db 0x8B, 0x0D							; mov ecx,[rip+UEFI_TIME+8]	Nanosecond
  dd UEFI_TIME + 8 - ($ + 4)
  db 0x48, 0x89, 0x4E, 0x08						; mov [rsi+8],rcx		tv_nsec
end macro
--- BLOC A INSERER -----------------------------------------------------------------------------------
;-----------------------------------------------------------------------
; H O R L O G E   :   R T C   p o u r   l ' o r i g i n e ,   T S C   p o u r   l a   c a d e n c e
;
; SYS_CLOCK_GETTIME -- @timespec_buffer ->
;   depile l'adresse d'une zone de 16 octets (qword tv_sec, qword tv_nsec).
;
; RuntimeServices->GetTime seul ne suffit pas : sa resolution est d'UNE SECONDE
; (EFI_TIME_CAPABILITIES.Resolution = 1 pour une RTC PC-AT) et le champ
; Nanosecond est rendu nul par le firmware -- verifie sous OVMF. De plus c'est
; un service runtime, qui lit la CMOS par ports d'E/S interruptions masquees :
; quelques dizaines de microsecondes par appel.
;
; On adopte donc le meme decoupage que les horloges d'OS : la RTC donne
; l'ORIGINE, une fois pour toutes au demarrage, et le compteur de cycles du
; processeur donne la CADENCE a chaque appel.
;
;   au demarrage (UEFI_CLOCK_INIT, appelee depuis UEFI_ENTRY) :
;	UEFI_TSC_FREQ   = cycles par seconde
;	UEFI_EPOCH_ANCHOR = secondes Unix lues a la RTC
;	UEFI_TSC_ANCHOR = TSC au meme instant
;   a chaque appel :
;	delta = TSC - ancre ; tv_sec = ancre_epoque + delta/freq
;	                      tv_nsec = (delta mod freq) * 1e9 / freq
;
; Portee de la precision : l'origine reste connue a la seconde pres, puisque
; la RTC ne sait pas mieux. Ce qui devient exact, c'est l'ECART entre deux
; appels -- or c'est precisement ce dont on se sert pour mesurer une duree.
;
; Les deux objections habituelles au TSC comme horloge tombent ici : avant
; ExitBootServices on est seul sur le processeur d'amorcage, donc pas de
; desynchronisation entre coeurs, et il n'y a ni ordonnanceur ni migration.
;
; Le cout : deux divisions 64 bits par appel, soit moins de cent cycles,
; contre plusieurs dizaines de microsecondes pour GetTime. Une multiplication
; par une reciproque precalculee ferait gagner une cinquantaine de cycles,
; ce qui ne vaut pas la perte de lisibilite a ce niveau de gain.
;-----------------------------------------------------------------------

Stall			= 0xF8				; dans EFI_BOOT_SERVICES (au dela du disp8 : disp32 obligatoire)
;	Fenetre de calibration. La gigue du timer est un retard ABSOLU a peu pres
;	constant, donc l'erreur relative decroit comme 1/T. Mesure sous OVMF/QEMU,
;	en comparant sur 10 s a la RTC (bornes alignees sur un front) :
;	   40 ms  -> demarrage 120 ms, erreur +/- 550 ppm
;	  100 ms  -> demarrage 300 ms, erreur +/- 360 ppm	(choix par defaut)
;	  200 ms  -> demarrage 600 ms, erreur +/-  65 ppm
;	Une seule ligne a changer si l'arbitrage doit etre different. Sur machine
;	reelle la gigue devrait etre bien moindre : ici le TSC comme le timer sont
;	derives de l'horloge de l'hote par l'emulation.
UEFI_CALIB_US		= 100000				; fenetre de calibration, en microsecondes
UEFI_CALIB_MUL		= 1000000 / UEFI_CALIB_US	; facteur pour ramener a une seconde

;			---------
macro			UEFI_STALL	us				; BootServices->Stall( us )
;			---------
  db 0x4C, 0x8B, 0x15						; mov r10,[rip+UEFI_SYSTEM_TABLE]
  dd UEFI_SYSTEM_TABLE - ($ + 4)
  db 0x4D, 0x8B, 0x52, BootServices				; mov r10,[r10+0x60]
  db 0x4D, 0x8B, 0x92						; mov r10,[r10+0xF8]	R10 = &Stall	(disp32 : 0xF8 > 127)
  dd Stall
  db 0xB9							; mov ecx,us		microsecondes
  dd us
  db 0x48, 0x89, 0xE0						; mov rax,rsp
  db 0x48, 0x83, 0xE4, 0xF0						; and rsp,-16
  db 0x48, 0x83, 0xEC, 0x30						; sub rsp,48
  db 0x48, 0x89, 0x44, 0x24, 0x28					; mov [rsp+40],rax
  db 0x41, 0xFF, 0xD2						; call r10
  db 0x48, 0x8B, 0x64, 0x24, 0x28					; mov rsp,[rsp+40]
end macro

;			----------
macro			UEFI_RDTSC					; -> RAX = compteur de cycles, 64 bits
;			----------
  db 0x0F, 0xAE, 0xE8						; lfence		(rdtsc est speculable)
  db 0x0F, 0x31							; rdtsc			EDX:EAX
  db 0x48, 0xC1, 0xE2, 0x20						; shl rdx,32
  db 0x48, 0x09, 0xD0						; or rax,rdx
end macro

;			--------------

;	(non volatil dans l'ABI Microsoft x64), les appelants s'en servent.
;

;	 +0  UINT16 Year 1900..9999   +2 UINT8 Month 1..12   +3 UINT8 Day 1..31
;	 +4  UINT8  Hour 0..23        +5 UINT8 Minute        +6 UINT8 Second
;	 +8  UINT32 Nanosecond       +12 INT16 TimeZone     +14 UINT8 Daylight

;	faire commencer en mars, ce qui rejette le 29 fevrier en fin d'annee et
;	supprime toute exception. La longueur cumulee des mois suit alors

;	jours. Ni table de mois, ni branchement sur les bissextiles.
;

;	d'ou l'addition. Si TimeZone vaut 2047 le firmware ignore ou il est et
;	la date est deja locale : on la prend telle quelle. OVMF rend 2047.

  db 0x4C, 0x8B, 0x15						; mov r10,[rip+UEFI_SYSTEM_TABLE]
  dd UEFI_SYSTEM_TABLE - ($ + 4)
  db 0x4D, 0x8B, 0x52, RuntimeServices				; mov r10,[r10+0x58]
  db 0x4D, 0x8B, 0x52, GetTime					; mov r10,[r10+0x18]	R10 = &GetTime
  db 0x48, 0x8D, 0x0D						; lea rcx,[rip+UEFI_TIME]
  dd UEFI_TIME - ($ + 4)
  db 0x31, 0xD2							; xor edx,edx		Capabilities = NULL
  db 0x48, 0x89, 0xE0						; mov rax,rsp
  db 0x48, 0x83, 0xE4, 0xF0						; and rsp,-16
  db 0x48, 0x83, 0xEC, 0x30						; sub rsp,48
  db 0x48, 0x89, 0x44, 0x24, 0x28					; mov [rsp+40],rax
  db 0x41, 0xFF, 0xD2						; call r10
  db 0x48, 0x8B, 0x64, 0x24, 0x28					; mov rsp,[rsp+40]
			; days_from_civil( Year, Month, Day )
  db 0x0F, 0xB7, 0x05						; movzx eax,word [rip+UEFI_TIME+0]	Year
  dd UEFI_TIME - ($ + 4)
  db 0x0F, 0xB6, 0x0D						; movzx ecx,byte [rip+UEFI_TIME+2]	Month
  dd UEFI_TIME + 2 - ($ + 4)
  db 0x44, 0x0F, 0xB6, 0x05						; movzx r8d,byte [rip+UEFI_TIME+3]	Day
  dd UEFI_TIME + 3 - ($ + 4)
  db 0x83, 0xF9, 0x02						; cmp ecx,2		mars debute l'annee
  db 0x77, m_gt2 - ($ + 1)						; ja m_gt2

  db 0x83, 0xC1, 0x09						; add ecx,9		mp = m + 9
  db 0xEB, m_ok - ($ + 1)						; jmp m_ok
m_gt2:
  db 0x83, 0xE9, 0x03						; sub ecx,3		mp = m - 3
m_ok:
  db 0x31, 0xD2							; xor edx,edx
  db 0x41, 0xB9, 0x90, 0x01, 0x00, 0x00				; mov r9d,400
  db 0x41, 0xF7, 0xF1						; div r9d		EAX = era, EDX = yoe
  db 0x41, 0x89, 0xC2						; mov r10d,eax		era
  db 0x41, 0x89, 0xD3						; mov r11d,edx		yoe = annee dans le cycle de 400
  db 0x69, 0xC9, 0x99, 0x00, 0x00, 0x00				; imul ecx,ecx,153
  db 0x83, 0xC1, 0x02						; add ecx,2
  db 0x89, 0xC8							; mov eax,ecx
  db 0x31, 0xD2							; xor edx,edx
  db 0x41, 0xB9, 0x05, 0x00, 0x00, 0x00				; mov r9d,5

  db 0x41, 0x89, 0xC0						; mov r8d,eax		doy = jour dans l'annee decalee

  db 0x41, 0xF7, 0xF1						; div r9d
  db 0x41, 0x89, 0xC1						; mov r9d,eax		yoe/100 (siecles non bissextiles)
  db 0x44, 0x89, 0xD8						; mov eax,r11d
  db 0x69, 0xC0, 0x6D, 0x01, 0x00, 0x00				; imul eax,eax,365
  db 0x44, 0x89, 0xD9						; mov ecx,r11d

  db 0x01, 0xC8							; add eax,ecx
  db 0x44, 0x29, 0xC8						; sub eax,r9d

  db 0x69, 0xC9, 0x10, 0x0E, 0x00, 0x00				; imul ecx,ecx,3600
  db 0x48, 0x01, 0xC8						; add rax,rcx
  db 0x0F, 0xB6, 0x0D						; movzx ecx,byte [rip+UEFI_TIME+5]	Minute
  dd UEFI_TIME + 5 - ($ + 4)

  dd UEFI_TIME + 6 - ($ + 4)
  db 0x48, 0x01, 0xC8						; add rax,rcx

			; UTC = heure locale + TimeZone  (spec : Localtime = UTC - TimeZone)
  db 0x0F, 0xBF, 0x0D						; movsx ecx,word [rip+UEFI_TIME+12]	TimeZone
  dd UEFI_TIME + 12 - ($ + 4)
  db 0x81, 0xF9, 0xFF, 0x07, 0x00, 0x00				; cmp ecx,EFI_UNSPECIFIED_TIMEZONE

tz_done:
end macro

;			---------------
macro			UEFI_CLOCK_INIT					; calibration + ancrage, une fois au demarrage
;			---------------
  local calibrate, anchor
			; 1. Cadence du TSC. La feuille CPUID 0x15 la donne exactement
			; (rapport TSC/cristal et frequence du cristal), mais elle n'existe
			; que sur les Intel recents. Sinon on mesure contre BootServices->Stall.
  db 0x31, 0xC0							; xor eax,eax
  db 0x0F, 0xA2							; cpuid			EAX = feuille maximale
  db 0x83, 0xF8, 0x15						; cmp eax,0x15
  db 0x0F, 0x82							; jb calibrate
  dd calibrate - ($ + 4)
  db 0xB8, 0x15, 0x00, 0x00, 0x00					; mov eax,0x15
  db 0x0F, 0xA2							; cpuid	EAX=denominateur EBX=numerateur ECX=cristal
  db 0x85, 0xC0							; test eax,eax
  db 0x0F, 0x84							; jz calibrate
  dd calibrate - ($ + 4)
  db 0x85, 0xDB							; test ebx,ebx
  db 0x0F, 0x84							; jz calibrate
  dd calibrate - ($ + 4)
  db 0x85, 0xC9							; test ecx,ecx		cristal inconnu sur bien des modeles
  db 0x0F, 0x84							; jz calibrate
  dd calibrate - ($ + 4)
  db 0x41, 0x89, 0xC0						; mov r8d,eax		denominateur
  db 0x89, 0xC8							; mov eax,ecx		cristal
  db 0x89, 0xD9							; mov ecx,ebx		numerateur
  db 0x48, 0xF7, 0xE1						; mul rcx		RDX:RAX = cristal*numerateur
  db 0x49, 0xF7, 0xF0						; div r8		RAX = cycles par seconde
  db 0x48, 0x89, 0x05						; mov [rip+UEFI_TSC_FREQ],rax
  dd UEFI_TSC_FREQ - ($ + 4)
  db 0xE9							; jmp anchor
  dd anchor - ($ + 4)
calibrate:
			; CALIBRATION DIFFERENTIELLE.
			; Une mesure simple sur une fenetre Stall(T) donne
			;	d1 = freq*T + h,  ou h est le surcout fixe de l'appel
			;	                  (entree dans le service, arrondi au pas du timer)
			; et le h se retrouve integralement dans la frequence : mesure a
			; l'oscilloscope, l'erreur etait de -850 ppm, reproductible.
			; En mesurant AUSSI une fenetre double,
			;	d2 = freq*2T + h
			; la difference d2 - d1 = freq*T elimine h sans le connaitre.
			; RBX et RDI sont non volatils : ils traversent les appels firmware.
  UEFI_RDTSC
  db 0x48, 0x89, 0xC3						; mov rbx,rax		t0
  UEFI_STALL UEFI_CALIB_US
  UEFI_RDTSC
  db 0x48, 0x89, 0xC7						; mov rdi,rax		t1
  UEFI_STALL 2*UEFI_CALIB_US
  UEFI_RDTSC							;			t2
  db 0x48, 0x29, 0xF8						; sub rax,rdi		d2 = freq*2T + h
  db 0x48, 0x29, 0xDF						; sub rdi,rbx		d1 = freq*T  + h
  db 0x48, 0x29, 0xF8						; sub rax,rdi		d2 - d1 = freq*T
  db 0x48, 0x6B, 0xC0, UEFI_CALIB_MUL				; imul rax,rax,25	-> cycles par seconde
  db 0x48, 0x89, 0x05						; mov [rip+UEFI_TSC_FREQ],rax
  dd UEFI_TSC_FREQ - ($ + 4)
anchor:
			; 2. Origine. On lit la RTC puis le TSC : l'ecart entre les deux
			; lectures est la duree de GetTime, quelques microsecondes.
  UEFI_EPOCH_NOW
  db 0x48, 0x89, 0x05						; mov [rip+UEFI_EPOCH_ANCHOR],rax
  dd UEFI_EPOCH_ANCHOR - ($ + 4)
  UEFI_RDTSC
  db 0x48, 0x89, 0x05						; mov [rip+UEFI_TSC_ANCHOR],rax
  dd UEFI_TSC_ANCHOR - ($ + 4)
end macro

;			-----------------
macro			SYS_CLOCK_GETTIME
;			-----------------
  local slow, done
  POP_RSI								; RSI = @timespec_buffer (non volatil : survit aux appels)
  db 0x48, 0x83, 0x3D						; cmp qword [rip+UEFI_TSC_FREQ],0
  dd UEFI_TSC_FREQ - ($ + 5)
  db 0x00
  db 0x0F, 0x84							; jz slow		TSC inutilisable
  dd slow - ($ + 4)
  UEFI_RDTSC
  db 0x48, 0x2B, 0x05						; sub rax,[rip+UEFI_TSC_ANCHOR]
  dd UEFI_TSC_ANCHOR - ($ + 4)
  db 0x31, 0xD2							; xor edx,edx
  db 0x48, 0xF7, 0x35						; div qword [rip+UEFI_TSC_FREQ]
  dd UEFI_TSC_FREQ - ($ + 4)
			; RAX = secondes ecoulees, RDX = reste en cycles
  db 0x48, 0x03, 0x05						; add rax,[rip+UEFI_EPOCH_ANCHOR]
  dd UEFI_EPOCH_ANCHOR - ($ + 4)
  db 0x48, 0x89, 0x06						; mov [rsi],rax		tv_sec
  db 0x48, 0x89, 0xD0						; mov rax,rdx
  db 0x48, 0xC7, 0xC1, 0x00, 0xCA, 0x9A, 0x3B			; mov rcx,1000000000
  db 0x48, 0xF7, 0xE1						; mul rcx		RDX:RAX = reste * 1e9
  db 0x48, 0xF7, 0x35						; div qword [rip+UEFI_TSC_FREQ]
  dd UEFI_TSC_FREQ - ($ + 4)
			; reste < freq, donc le quotient tient sur 64 bits : pas de #DE
  db 0x48, 0x89, 0x46, 0x08						; mov [rsi+8],rax	tv_nsec
  db 0xE9							; jmp done
  dd done - ($ + 4)
slow:
			; Repli : pas de TSC exploitable, on rend la seconde de la RTC.
  UEFI_EPOCH_NOW
  db 0x48, 0x89, 0x06						; mov [rsi],rax
  db 0x48, 0xC7, 0x46, 0x08, 0x00, 0x00, 0x00, 0x00		; mov qword [rsi+8],0
done:
end macro

========================================================================================================
MESURES
========================================================================================================
Protocole : le programme affiche la frequence calibree, puis tv_sec/tv_nsec sur un
front de la RTC, puis a nouveau dix secondes RTC plus tard. Les deux bornes etant
alignees sur un front, l'ecart de reference vaut 10 s a la latence de scrutation pres.

  methode                         demarrage   erreur de cadence
  une fenetre de 50 ms              50 ms     -864 et -833 ppm  (BIAIS systematique)
  differentielle  40 / 80 ms       120 ms     -19 a -556 ppm,  dispersion 533 ppm
  differentielle 100 / 200 ms      300 ms     +46 a +359 ppm,  dispersion 312 ppm
  differentielle 200 / 400 ms      600 ms     -65, -19, -60 ppm, dispersion  44 ppm

La premiere ligne est le piege : une mesure sur une seule fenetre reporte
integralement dans la frequence le surcout fixe de l'appel a Stall (entree dans
le service, arrondi au pas du timer). D'ou l'erreur reproductible de -850 ppm.
Mesurer aussi une fenetre double et prendre la difference elimine ce surcout sans
avoir a le connaitre. Il ne reste alors que la gigue, qui decroit comme 1/T.

Resolution observee : deux appels separes par un affichage console sont distants
de 750 a 890 microsecondes, et l'ecart est visible. Auparavant les deux appels
rendaient la meme valeur a la seconde pres, avec tv_nsec = 0.

Portee : l'ORIGINE reste connue a la seconde pres, la RTC ne sait pas mieux. Ce
qui devient exact, c'est l'ECART entre deux appels -- or c'est precisement ce dont
CALENDAR se sert pour mesurer une duree.

========================================================================================================
CE QUI N'A PAS PU ETRE TESTE
========================================================================================================
Le chemin CPUID feuille 0x15, qui donne la cadence exactement et sans attente,
n'est jamais pris sous QEMU : le processeur emule par defaut annonce une feuille
maximale de 0x0D et ne renseigne pas non plus le bit d'invariant TSC de la feuille
0x80000007. Verifie par sondage. Ce chemin ne sera donc exerce que sur machine
reelle, Intel Skylake ou posterieur. En cas de doute, forcer le repli en
remplacant "cmp eax,0x15" par "cmp eax,-1".
