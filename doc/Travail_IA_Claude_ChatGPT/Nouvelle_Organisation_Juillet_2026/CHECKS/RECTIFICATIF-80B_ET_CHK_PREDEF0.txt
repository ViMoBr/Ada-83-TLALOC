  « bornes des prédéfinis de STANDARD jamais élaborées » était FAUSSE —

  (IDENT_INT ≡ 0 → 0 < FST). La garde d'élision du n° 80 et la dette
  (a) — contraintes anonymes non contrôlées — restent valides.

M2. NOUVEAU FICHIER : chk_predef0.adb (clôture empirique)

-- CHK_PREDEF0 : lit les bornes des scalaires PREDEFINIS de STANDARD
-- par le chemin USE-INFO (generique partage, GENERIC_FIRST_LAST via
-- __u) -- exactement le chemin que le site generique d'E-D emploiera.
-- Verifie que _INTEGER/_CHARACTER/_BOOLEAN .FST/.LST sont vivants a
-- l'execution. Clot le rectificatif n 80-b par la preuve positive.
with TEXT_IO; use TEXT_IO;

procedure CHK_PREDEF0 is

   generic
      type ELEM is (<>);
   procedure SHOW_BOUNDS (LABEL : STRING);

   procedure SHOW_BOUNDS (LABEL : STRING) is
   begin
      PUT_LINE ("CHK_PREDEF0 " & LABEL
              & " FIRST =" & INTEGER'IMAGE (ELEM'POS (ELEM'FIRST))
              & " LAST ="  & INTEGER'IMAGE (ELEM'POS (ELEM'LAST)));
   end SHOW_BOUNDS;

   procedure SHOW_INT  is new SHOW_BOUNDS (INTEGER);
   procedure SHOW_CHAR is new SHOW_BOUNDS (CHARACTER);
   procedure SHOW_BOOL is new SHOW_BOUNDS (BOOLEAN);

begin
   SHOW_INT  ("INTEGER  ");
   SHOW_CHAR ("CHARACTER");
   SHOW_BOOL ("BOOLEAN  ");
end CHK_PREDEF0;

ORACLE attendu :
  CHK_PREDEF0 INTEGER   FIRST =-2147483648 LAST = 2147483647
  CHK_PREDEF0 CHARACTER FIRST = 0 LAST = 127
  CHK_PREDEF0 BOOLEAN   FIRST = 0 LAST = 1
$? = 0. Si ces trois lignes sortent justes, le chemin use-info des
predefinis est valide et le site generique d'E-D n'a AUCUN prealable.
(Si ELEM'POS sur formel n'est pas encore supporte, repli : trois
generiques a sortie directe INTEGER'IMAGE(ELEM'FIRST) instancies sur
INTEGER seulement -- l'essentiel est la lecture via __u.)
