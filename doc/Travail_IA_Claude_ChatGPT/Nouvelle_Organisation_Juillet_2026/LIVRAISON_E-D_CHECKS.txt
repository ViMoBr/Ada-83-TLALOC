LIVRAISON E-D -- PILIER CHECKS : GAMME SCALAIRE, LES SIX SITES RESTANTS
Sous-etapes independantes E-D1..E-D6, a coller et juger UNE PAR UNE
(temoin progressif M7). Reference : note v1.3 §3 bis (source des bornes
uniforme), §5 (elision), Q6 close (chemin generique valide CHK_PREDEF0).
Partout : le meme CODE_RANGE_CHECK d'E-A, garde n 80 comprise.
========================================================================

E-D1. INIT DE DECLARATION -- expander-declarations.adb, CODE_VC_NAME
----------------------------------------------------------------------
Branche "variable entiere" (et sa jumelle enumeree si distincte).
ANCRE : les lignes existantes :

	if  INIT_EXP /= TREE_VOID  then
	  EXPRESSIONS.CODE_EXP( INIT_EXP );
	  CODI.STORE( VC_NAME );
	end if;

REMPLACER PAR :

	if  INIT_EXP /= TREE_VOID  then
	  EXPRESSIONS.CODE_EXP( INIT_EXP );
	  EXPRESSIONS.CODE_RANGE_CHECK( TYPE_SPEC );						-- E-D1 : gamme du sous-type de l'objet
	  CODI.STORE( VC_NAME );
	end if;

(TYPE_SPEC est en portee -- la cascade branche dessus. Si la branche
enumeree a sa propre paire CODE_EXP/STORE, meme insertion. La branche
fixed NE recoit RIEN : perimetre 2, CODE_RANGE_CHECK l'ignorerait de
toute facon. Sous-types anonymes d'objet : garde n 80 -> elision,
dette (a) inchangee.)

E-D2. PARAMETRE IN -- expander-instructions.adb, CODE_PROCEDURE_CALL
----------------------------------------------------------------------
UN SEUL point d'insertion : en FIN de cascade des formes d'actuel
(apres le if/elsif sur ACT_PRM.TY / DEFN.TY, avant le passage a
l'actuel suivant), quand la valeur vient d'etre posee :

	  -- E-D2 : gamme du SOUS-TYPE DU FORMEL (LRM 6.4.1), mode in seul.
	  -- Les modes out/in_out posent une ADRESSE : pas de check ici
	  -- (copy-back hors perimetre 1, consigne).
	  if  FRM_PRM_ID.TY = DN_IN_ID  then
	    EXPRESSIONS.CODE_RANGE_CHECK( D( SM_OBJ_TYPE, FRM_PRM_ID ) );
	  end if;

ANCRE a localiser au collage : le point unique en queue de boucle ou
TOUTES les formes d'actuel IN scalaire ont leur valeur au sommet
(variable LOAD_MEM, constante n 81, expression CODE_EXP). Si la boucle
n'a pas de queue commune, inserer la meme paire de lignes en fin de
CHAQUE branche IN scalaire -- au juge CHK_TEST1 §2 de trancher.
(CODE_RANGE_CHECK elide de lui-meme les formels au type de base --
IDENT_INT(X : INTEGER) ne recoit aucun check, tant mieux.)

E-D3. RETURN -- expander-instructions.adb, CODE_RETURN
----------------------------------------------------------------------
Chemin du sous-type de retour (verifie au dump REPORT) :
ENCLOSING_BODY -> AS_HEADER -> AS_NAME -> SM_DEFN -> SM_TYPE_SPEC.
ANCRE : les lignes existantes :

	if  EXPR_TYPE.TY in CLASS_SCALAR  or else  EXPR_TYPE.TY = DN_ACCESS  then
	  EXPRESSIONS.CODE_EXP( EXP );
	  PUT_LINE( tab & "S" & CODI.EXP_TYPE_CHAR( EXP ) & ' ' & INTEGER'IMAGE( CODI.CUR_LEVEL ) & ',' & tab & "-result__ofs" );

REMPLACER PAR :

	if  EXPR_TYPE.TY in CLASS_SCALAR  or else  EXPR_TYPE.TY = DN_ACCESS  then
	  EXPRESSIONS.CODE_EXP( EXP );
	  if  EXPR_TYPE.TY /= DN_ACCESS  then							-- E-D3 : gamme du SOUS-TYPE DE RETOUR --
	    EXPRESSIONS.CODE_RANGE_CHECK(							-- l'expression porte le type de BASE
	      D( SM_TYPE_SPEC, D( SM_DEFN, D( AS_NAME,						-- (dump CHK_DUMP0), le sous-type vit dans
	        D( AS_HEADER, CODI.ENCLOSING_BODY ) ) ) ) );					-- le FUNCTION_SPEC (dump REPORT).
	  end if;
	  PUT_LINE( tab & "S" & CODI.EXP_TYPE_CHAR( EXP ) & ' ' & INTEGER'IMAGE( CODI.CUR_LEVEL ) & ',' & tab & "-result__ofs" );

(Return dans un bloc imbrique : ENCLOSING_BODY designe le sous-
programme -- CHK_TEST1 §3 le juge avec un return depuis un declare.)

E-D4. CONVERSION -- expander-expressions.adb, CODE_CONVERSION
----------------------------------------------------------------------
Insertion en FIN de procedure, quand la valeur convertie est au sommet
dans la representation cible, sur les chemins SCALAIRES uniquement
(chemin statique LI compris -- une valeur statique hors bornes
dynamiques doit lever ; l'elision statique totale reste consignee) :

	  EXPRESSIONS_CODE_RANGE_CHECK :							-- E-D4 : gamme du sous-type CIBLE (4.6)
	  CODE_RANGE_CHECK( TARGET_TYPE );

ANCRE a confirmer au collage : le(s) point(s) de sortie des chemins
scalaires de CODE_CONVERSION (apres conversion de representation
eventuelle CVTIX/CVTXI/FLT, avant le retour). Les chemins composites
(conversion de tableaux) ne recoivent rien.

E-D5. QUALIFICATION -- expander-expressions.adb, CODE_QUALIFIED
----------------------------------------------------------------------
Meme geste : en fin de CODE_QUALIFIED, chemins scalaires,

	  CODE_RANGE_CHECK( D( SM_EXP_TYPE, QUALIFIED ) );					-- E-D5 : gamme du sous-type qualifie (4.7)

(nom du parametre formel de la procedure a ajuster a l'existant).

E-D6. CORPS GENERIQUE PARTAGE -- expander-instructions.adb,
      CODE_ASSIGN, branche "AUTRE TYPE SCALAIRE (formel generique)"
----------------------------------------------------------------------
Bornes du FORMEL a l'execution via le dictionnaire d'instance --
chemin GENERIC_FIRST_LAST valide par CHK_PREDEF0. ANCRE : la branche :

	else											-- AUTRE TYPE SCALAIRE (type formel generique, etc.)
	  if  CODI.IN_GENERIC_BODY  and then  ( DEFN.TY = DN_OUT_ID  or  DEFN.TY = DN_IN_OUT_ID )  then
	    PUT_LINE( tab & "LVa " & INTEGER'IMAGE( DI( CD_LEVEL, DEFN ) ) & ',' & tab & '-' & PRINT_NAME( D( LX_SYMREP, DEFN ) ) & "_ofs" );
	    PUT_LINE( tab & "La" );
	  end if;
	  EXPRESSIONS.CODE_EXP( SRC_EXP );
	  STORE_OR_CALLI;

INSERER entre CODE_EXP et STORE_OR_CALLI, garde IN_GENERIC_BODY et
IS_GENERIC_FORMAL_TYPE, l'idiome aux bornes du formel (calquer les
lignes de GENERIC_FIRST_LAST, expressions ~1831, pour le prefixe __u
exact -- CHN_PREFIX de la variable cible) :

	  DUP ; LId , -<CHN>__u_ofs, STANDARD._ENUM_USE_INFO.FST ; CLT ; BT STANDARD.ce_raise_
	  DUP ; LId , -<CHN>__u_ofs, STANDARD._ENUM_USE_INFO.LST ; CGT ; BT STANDARD.ce_raise_

AUCUNE elision en corps partage (note §9 Q6). C'est le seul site ou le
check ne passe PAS par CODE_RANGE_CHECK : consigner en commentaire.

M7. TEMOIN PROGRESSIF : chk_test1.adb
----------------------------------------------------------------------
-- CHK_TEST1 : temoin E-D, une section par site. VERDISSEMENT
-- PROGRESSIF : avant la pose du site n, sa section imprime
-- "KO pas de levee" -- ATTENDU. Tout vert = E-D complete.
with TEXT_IO; use TEXT_IO;
procedure CHK_TEST1 is
   subtype SMALL is INTEGER range 1 .. 10;
   N : INTEGER := 20;
   function CLIP (P : SMALL) return SMALL is
   begin
      return P;
   end CLIP;
   function GROW (P : INTEGER) return SMALL is
   begin
      declare
         D : INTEGER := P + P;
      begin
         return D;                       -- §3 : return depuis un bloc
      end;
   end GROW;
   generic
      type ELEM is (<>);
   procedure GSET (X : in out ELEM; SRC : in out ELEM);
   procedure GSET (X : in out ELEM; SRC : in out ELEM) is
   begin
      X := SRC;                          -- §6 : affectation en corps partage
   end GSET;
   procedure SSET is new GSET (SMALL);
   S : SMALL := 5;
   B : INTEGER := 7;                     -- valeur licite pour §1..§5 in-range
   R : INTEGER := 0;
begin
   begin                                 -- §1 : init de declaration
      declare
         X : SMALL := N;                 -- 20 hors 1..10
      begin
         R := X;
         PUT_LINE ("CHK_TEST1 1 KO pas de levee");
      end;
   exception
      when CONSTRAINT_ERROR => PUT_LINE ("CHK_TEST1 1 OK init de declaration");
   end;
   begin                                 -- §2 : parametre in
      R := CLIP (N);
      PUT_LINE ("CHK_TEST1 2 KO pas de levee");
   exception
      when CONSTRAINT_ERROR => PUT_LINE ("CHK_TEST1 2 OK parametre in");
   end;
   begin                                 -- §3 : return (7+7=14 hors 1..10)
      R := GROW (B);
      PUT_LINE ("CHK_TEST1 3 KO pas de levee");
   exception
      when CONSTRAINT_ERROR => PUT_LINE ("CHK_TEST1 3 OK return");
   end;
   begin                                 -- §4 : conversion
      R := SMALL (N);
      PUT_LINE ("CHK_TEST1 4 KO pas de levee");
   exception
      when CONSTRAINT_ERROR => PUT_LINE ("CHK_TEST1 4 OK conversion");
   end;
   begin                                 -- §5 : qualification
      R := SMALL'(N);
      PUT_LINE ("CHK_TEST1 5 KO pas de levee");
   exception
      when CONSTRAINT_ERROR => PUT_LINE ("CHK_TEST1 5 OK qualification");
   end;
   begin                                 -- §6 : corps generique partage
      declare
         T : SMALL := 3;
         U : SMALL := 9;
      begin
         SSET (T, U);                    -- licite : U=9 dans 1..10
         PUT_LINE ("CHK_TEST1 6a OK generique licite, T =" & INTEGER'IMAGE (T));
      end;
      SSET (S, S);                       -- licite aussi ; le cas HORS bornes
      PUT_LINE ("CHK_TEST1 6b consigne : violation generique testable");
      -- quand un moyen licite Ada de passer une valeur hors bornes du
      -- formel existera (via base non contrainte), etendre ce temoin.
   end;
   -- §7 : rien n'a leve a tort, valeurs saines
   if  R = 0  and  S = 5  then
      PUT_LINE ("CHK_TEST1 7 OK aucune levee parasite");
   else
      PUT_LINE ("CHK_TEST1 7 KO R =" & INTEGER'IMAGE (R));
   end if;
   -- §8 : non rattrapee -> sentinelle (DERNIERE section)
   PUT_LINE ("CHK_TEST1 8 attendu : EXCEPTION NON RATTRAPEE : CONSTRAINT_ERROR, $? = 1");
   R := CLIP (N) + 1;
   PUT_LINE ("CHK_TEST1 8 KO ligne atteinte");
end CHK_TEST1;

ORACLE final : 1..5 OK, 6a OK (T = 9), 7 OK, 8 sentinelle, $? = 1.
Ordre de pose conseille : D1, D2, D3, D4, D5, D6 -- temoin apres
CHAQUE pose (sa section verdit, les suivantes restent KO-attendu),
filet complet apres D3 puis apres D6 (les sites param-in et return
traversent tout le corpus : fossiles possibles, regle de tri §7).
