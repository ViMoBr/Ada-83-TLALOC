LA SONDE A TOUT DIT : rcx = 8 (longueurs justes), rsi = "BxyzBBBB" (la
constante est saine), rdi = "CxyzCCCC" — GA(2) contient des C.  Les trois
inits ont écrit À LA MÊME ADRESSE (la dernière gagne), la tranche a posé
"xyz" à +1 du même bloc, et le test 2 comparait deux lectures du même
endroit — cohérent-mais-seul.  L'offset d'indexation vaut 0 pour tout i.

VOTRE FINC porte le pistolet fumant, élaboration de _ROW :
	LI 0 / Sd 1, _COMP_SIZ
donc SIZ = 3×0 = 0 : GA est alloué à ZÉRO OCTET sur la co-pile, tous les
GA(i) s'effondrent sur GA+0, et les écritures débordent sur les blocs
voisins de la co-pile.  Le segfault de S2 est un dégât collatéral du même
effondrement.  Cause première : COMPILE_ARRAY_TYPE_DIMENSION lit la
taille du composant dans CD_IMPL_SIZE — non posé sur les sous-types
composants ANONYMES (le même attribut muet que FIX-LEN v2/v3, troisième
morsure).  Le remède du record voisin (taille symbolique <rec>.size*8,
ACVC A7) ne s'applique pas : les blocs tableaux n'ont pas de .size
(établi au FIX-LEN v2).

REMÈDE : une branche elsif DN_CONSTRAINED_ARRAY qui calcule la taille
STATIQUEMENT à l'expansion — (LST−FST+1) × taille du sous-composant,
bornes par SM_INDEX_SUBTYPE_S (l'idiome C6-v2, précédent de l'attribut
'FIRST) et STATIC_BOUND_VALUE, la règle exportée des bornes statiques.
Pour STRING(1..8) : 8 × 8 = LI 64.  Non statique, multi-dimension, ou
sous-composant de taille inconnue : TROU bruyant + LI 0 d'équilibre
(FINC SUSPECT) — plus jamais de zéro muet.  Le chemin CD_IMPL_SIZE ≠ 0
(composants nommés, scalaires — tout le corpus) est INTACT byte à byte.

MODIF FIX-COMPSIZ — expander-declarations-types_decls.adb,
COMPILE_ARRAY_TYPE_DIMENSION (dernière dimension)
--------------------------------------------------------------------------------
  ANCRE (unique, 4 lignes au-dessus) :
	ARRAY_STATIC_SIZE := ELEMENT_SIZ;

  BLOC À SUPPRIMER (unique — le if record/else LI complet) :
	if  ELEMENT_SIZ = 0
	  and then ( COMP_TYPE.TY = DN_RECORD  or else  COMP_TYPE.TY = DN_CONSTRAINED_RECORD )
	then
		-- Pilier 3.7 / ACVC A7 : composant record dont la vue complete
		-- (type prive) n'est pas encore compilee.  Taille inconnue de
		-- l'EXPANDER mais pas de l'ASSEMBLEUR : emettre le symbole
		-- <rec>.size*8, defini plus loin dans le meme FINC (fasm est
		-- multi-passes).  Le tableau suit le chemin dynamique.
	  IS_STATIC := FALSE;

	  declare
	    REC	: TREE	:= COMP_TYPE;
	  begin
	    if  REC.TY = DN_CONSTRAINED_RECORD  then
	      REC := D( SM_BASE_TYPE, REC );
	    end if;

	    declare
	      REC_NAME	: TREE		:= D( XD_SOURCE_NAME, REC );
	      REC_STR	:constant STRING	:= '_' & PRINT_NAME( D( LX_SYMREP, REC_NAME ) );
	    begin
	      PUT( tab & "LI" & tab );
	      CODI.REGIONS_PATH( REC_NAME );
	      PUT_LINE( REC_STR & ".size*8" );							-- TAILLE SYMBOLIQUE (bits)
	    end;
	  end;

	else
	  PUT_LINE(	tab & "LI" & tab & ELEMENT_SIZ_STR );						-- TAILLE D'UN ELEMENT DU TABLEAU
	end if;

  BLOC DE REMPLACEMENT (branche record INTACTE ; elsif inséré ; else
  final INTACT) :
	if  ELEMENT_SIZ = 0
	  and then ( COMP_TYPE.TY = DN_RECORD  or else  COMP_TYPE.TY = DN_CONSTRAINED_RECORD )
	then
		-- Pilier 3.7 / ACVC A7 : composant record dont la vue complete
		-- (type prive) n'est pas encore compilee.  Taille inconnue de
		-- l'EXPANDER mais pas de l'ASSEMBLEUR : emettre le symbole
		-- <rec>.size*8, defini plus loin dans le meme FINC (fasm est
		-- multi-passes).  Le tableau suit le chemin dynamique.
	  IS_STATIC := FALSE;

	  declare
	    REC	: TREE	:= COMP_TYPE;
	  begin
	    if  REC.TY = DN_CONSTRAINED_RECORD  then
	      REC := D( SM_BASE_TYPE, REC );
	    end if;

	    declare
	      REC_NAME	: TREE		:= D( XD_SOURCE_NAME, REC );
	      REC_STR	:constant STRING	:= '_' & PRINT_NAME( D( LX_SYMREP, REC_NAME ) );
	    begin
	      PUT( tab & "LI" & tab );
	      CODI.REGIONS_PATH( REC_NAME );
	      PUT_LINE( REC_STR & ".size*8" );							-- TAILLE SYMBOLIQUE (bits)
	    end;
	  end;

	elsif  ELEMENT_SIZ = 0  and then  COMP_TYPE.TY = DN_CONSTRAINED_ARRAY  then
			--| FIX 30/07 (paye par SLICE1 sous gdb : _ROW._COMP_SIZ emis LI 0,
			--| SIZ = 3*0 = 0, GA alloue a ZERO octet sur la co-pile, tous les
			--| GA(i) effondres sur la meme adresse -- rdi montrait CxyzCCCC).
			--| Composant tableau contraint ANONYME : CD_IMPL_SIZE non pose
			--| (meme attribut muet que FIX-LEN v2/v3), et PAS de symbole .size
			--| pour les blocs tableaux (etabli au FIX-LEN v2) -- la voie du
			--| record ne s'applique pas.  Taille STATIQUE calculee ici :
			--| (LST-FST+1) * taille du sous-composant, bornes par
			--| SM_INDEX_SUBTYPE_S (idiome C6-v2, precedent attribut 'FIRST) ;
			--| STATIC_BOUND_VALUE est la regle exportee des bornes statiques.
			--| Non statique, multi-dimension ou sous-composant de taille
			--| inconnue : TROU, bruyant -- jamais de LI 0 muet.
	  declare
	    C_IDX_S	: SEQ_TYPE	:= LIST( D( SM_INDEX_SUBTYPE_S, COMP_TYPE ) );
	    C_IDX	: TREE;
	    C_BASE	: TREE	:= D( SM_BASE_TYPE, COMP_TYPE );
	    LO, HI	: INTEGER;
	    LO_OK	: BOOLEAN;
	    HI_OK	: BOOLEAN;
	    SUB_SIZ	: INTEGER	:= 0;
	  begin
	    POP( C_IDX_S, C_IDX );
	    CODI.STATIC_BOUND_VALUE( D( AS_EXP1, D( SM_RANGE, C_IDX ) ), LO, LO_OK );
	    CODI.STATIC_BOUND_VALUE( D( AS_EXP2, D( SM_RANGE, C_IDX ) ), HI, HI_OK );
	    SUB_SIZ := DI( CD_IMPL_SIZE, D( SM_COMP_TYPE, C_BASE ) );

	    if  LO_OK  and then  HI_OK  and then  SUB_SIZ > 0
	    and then  IS_EMPTY( C_IDX_S )  and then  HI >= LO  then
	      ELEMENT_SIZ := NATURAL( ( HI - LO + 1 ) * SUB_SIZ );
	      ARRAY_STATIC_SIZE := ELEMENT_SIZ;
	      PUT_LINE( tab & "LI" & tab & IMAGE( INTEGER( ELEMENT_SIZ ) ) );				-- TAILLE STATIQUE (bits)
	    else
	      CODI.TROU( "COMP_SIZ composant tableau anonyme non statique (bornes/sous-composant/dimensions)", COMP_TYPE );
	      PUT_LINE( tab & "LI" & tab & '0' );							-- equilibre de pile, FINC SUSPECT
	    end if;
	  end;

	else
	  PUT_LINE(	tab & "LI" & tab & ELEMENT_SIZ_STR );						-- TAILLE D'UN ELEMENT DU TABLEAU
	end if;
