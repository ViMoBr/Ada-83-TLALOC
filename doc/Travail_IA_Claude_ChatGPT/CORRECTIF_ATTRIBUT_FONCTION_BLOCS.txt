CORRECTIF ATTRIBUT-FONCTION -- expander-expressions.adb, CODE_ATTRIBUTE
4 blocs AVANT/APRES (POS, PRED, SUCC, VAL), l.~2849-2900.

CONTRAT REVELE PAR LE RECENSEMENT (28/07/2026, temoin _STANDRD
INTEGER_IMAGE / ENUM_IMAGE) : T'POS(X) & co arrivent en FORME APPEL
(DN_FUNCTION_CALL de nom DN_ATTRIBUTE) ; CODE_FUNCTION_CALL evalue
l'actuel PUIS appelle CODE_ATTRIBUTE -- l'argument est DEJA en pile a
l'entree de ces branches, et AS_EXP du noeud attribut est TOUJOURS
vide sur cette forme. Le CODE_EXP( D( AS_EXP, ... ) ) etait un no-op
silencieux depuis l'origine ; POS/VAL (identite) et PRED/SUCC
(DEC/INC sur le sommet) marchaient grace a l'appelant. On supprime
l'appel vestigial et on INVERSE la ceinture : le cas vide est le
legitime, le cas peuple (forme directe jamais emise par le frontend)
devient le TROU.

BLOC 1 -- 'POS
AVANT :
      elsif  CHN_ATTR( 2 ) = 'O'  then					-- POS
        -- T'POS(X) : retourne le numero d'ordre (identite sans clause de rep)
        CODE_EXP( D( AS_EXP, ATTRIBUTE ) );
APRES :
      elsif  CHN_ATTR( 2 ) = 'O'  then					-- POS
        -- T'POS(X) : numero d'ordre = identite (sans clause de rep).
        -- CONTRAT forme appel : l'argument est evalue et empile par
        -- CODE_FUNCTION_CALL avant d'arriver ici ; AS_EXP est vide
        -- (recensement 28/07). Rien a emettre.
        if  D( AS_EXP, ATTRIBUTE ) /= TREE_VOID  then
	TROU( "CODE_ATTRIBUTE 'POS : forme directe AS_EXP imprevue" );
        end if;


BLOC 2 -- 'PRED
AVANT :
      elsif  CHN_ATTR( 2 ) = 'R'  then					-- PRED
        -- T'PRED(X) : retourne X-1
        CODE_EXP( D( AS_EXP, ATTRIBUTE ) );
        PUT_LINE( tab & "DEC" );
APRES :
      elsif  CHN_ATTR( 2 ) = 'R'  then					-- PRED
        -- T'PRED(X) = X-1 sur l'argument DEJA en pile (contrat forme
        -- appel, cf. 'POS).
        if  D( AS_EXP, ATTRIBUTE ) /= TREE_VOID  then
	TROU( "CODE_ATTRIBUTE 'PRED : forme directe AS_EXP imprevue" );
        end if;
        PUT_LINE( tab & "DEC" );


BLOC 3 -- 'SUCC
AVANT :
      elsif  CHN_ATTR( 2 ) = 'U'  then					-- SUCC
        -- T'SUCC(X) : retourne X+1
        CODE_EXP( D( AS_EXP, ATTRIBUTE ) );
        PUT_LINE( tab & "INC" );
APRES :
      elsif  CHN_ATTR( 2 ) = 'U'  then					-- SUCC
        -- T'SUCC(X) = X+1 sur l'argument DEJA en pile (contrat forme
        -- appel, cf. 'POS).
        if  D( AS_EXP, ATTRIBUTE ) /= TREE_VOID  then
	TROU( "CODE_ATTRIBUTE 'SUCC : forme directe AS_EXP imprevue" );
        end if;
        PUT_LINE( tab & "INC" );


BLOC 4 -- 'VAL
AVANT :
      else								-- VAL
        -- T'VAL(N) : retourne la valeur de position N (identite sans clause de rep)
        CODE_EXP( D( AS_EXP, ATTRIBUTE ) );
APRES :
      else								-- VAL
        -- T'VAL(N) : valeur de position = identite (sans clause de
        -- rep), argument DEJA en pile (contrat forme appel, cf. 'POS).
        if  D( AS_EXP, ATTRIBUTE ) /= TREE_VOID  then
	TROU( "CODE_ATTRIBUTE 'VAL : forme directe AS_EXP imprevue" );
        end if;

NOTES
========================================================================
1. NE PAS remplacer par une simple suppression sans ceinture : DIANA
   prevoit bien un slot as_exp sur le noeud attribute (diana_NODES
   l.754-760). Si un jour sem/le frontend emettait la forme directe,
   POS/VAL n'empileraient RIEN -- exactement un n 115. La ceinture
   inversee le crierait au site.

2. ORACLE apres collage : re-expanser _STANDRD en STRICT -- plus aucun
   TROU sur INTEGER_IMAGE / ENUM_IMAGE, et le FINC de ces deux zones
   doit etre IDENTIQUE a celui d'avant la vague 1 (le no-op supprime
   n'emettait rien) : diff des FINC = oracle gratuit de non-regression.
   Puis re-run RECENSEMENT corpus complet : ce motif etant
   vraisemblablement LE gros fournisseur de "CODE_EXP( TREE_VOID )",
   le reliquat de cris, s'il y en a, vient d'ailleurs et se triera de
   la meme facon (grep -B 12 sur les FINC).

3. ENTREE PIEGES a consigner : « attribut-fonction : l'argument est
   evalue par CODE_FUNCTION_CALL, PAS par CODE_ATTRIBUTE -- AS_EXP du
   noeud attribut est vide sur la forme appel. Contrat invisible
   depuis l'origine, revele par la discipline TROU() (le no-op
   CODE_EXP(TREE_VOID) le masquait) ; PRED/SUCC ne marchaient que par
   l'argument de l'appelant deja en pile. » -- avec le n de la
   discipline TROU en reference croisee.
