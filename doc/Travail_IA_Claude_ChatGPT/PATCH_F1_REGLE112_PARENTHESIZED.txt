DIAGNOSTIC FERMÉ — le mensonge est une DÉRÉFÉRENCE MANQUANTE

Le PRO _LE__L31 dit tout. Le corps Ada est nécessairement de la forme
    return  ( LEFT <= RIGHT ) = U_VAL( 1 );
(parenthèses OBLIGATOIRES : deux opérateurs relationnels ne s'associent
pas en Ada). L'égalité de records représentés (chemin « representation
pleine d'un mot unique » de CODE_RECORD_EQUALITY) doit charger les DEUX
mots : @doublet -> data_ptr (La) -> mot (Ld). Or le FINC montre :

  opérande GAUCHE  (le résultat de _LE__L27) :   CALL ... / Ld
  opérande DROIT   (le résultat de U_VAL)     :   CALL ... / La , 0 / Ld

Le gauche saute le « La » : le Ld charge les 32 bits bas de l'ADRESSE
du doublet anonyme (une adresse de pile), et le CEQ compare cette
adresse à la valeur du TREE U_VAL(1). Jamais égales -> 0 -> FALSE
permanent, pour _LE__L31 comme pour _GE__L32 (même motif mot pour mot).
Toute la chaîne des symptômes est expliquée : les six booléens FFFFFF,
l'erreur type A de text_io/direct_io, et l'innocence de tout le reste.

POURQUOI le gauche et pas le droit : OPERAND_DATA_ADDRESS (la procédure
locale de CODE_RECORD_EQUALITY) discrimine par ESPÈCE :
    if E.TY = DN_USED_OBJECT_ID or else E.TY = DN_FUNCTION_CALL then La
U_VAL(1) est un DN_FUNCTION_CALL nu -> La émis. ( LEFT <= RIGHT ) est
un DN_PARENTHESIZED enveloppant le DN_FUNCTION_CALL -> le test échoue,
pas de La. C'est la CINQUIÈME occurrence de la famille n°112 (producteur
d'@doublet absent d'une discrimination par espèce), avec DEUX
circonstances aggravantes déjà nommées par le dépôt lui-même :
  1. OPERAND_DATA_ADDRESS est une COPIE LOCALE divergente de la règle
     unique — le commentaire de CODE_COMPOSITE_DATA_ADDRESS dit
     « discrimination d'OPERAND_DATA_ADDRESS érigée en règle unique »,
     mais le site d'origine n'a jamais été rebranché dessus ; l'audit
     recommandé au journal du 7 août l'aurait attrapé ;
  2. la règle unique ELLE-MÊME ne déballe pas DN_PARENTHESIZED (elle
     déballe DN_CONVERSION depuis C1-ter) : frère latent partout,
     p.ex. « T : TREE := ( D(...) ); » miscompilerait aujourd'hui.

Le correctif traite les deux : la règle unique apprend PARENTHESIZED
(identité de forme, même argument que C1-ter : CODE_PARENTHESIZED =
CODE_EXP de l'AS_EXP), et OPERAND_DATA_ADDRESS délègue à la règle
unique (sa garde agrégat, hors contrat de la règle, est conservée).
Note d'équivalence d'émission : la règle émet « La » nu là où la copie
locale émettait « La  ,  0 » — formes équivalentes (défauts -1, 0,
même convention documentée pour Ld), et « La » nu est la forme prouvée
par tout le bootstrap aux sites C6/C8.
