  CONCEPTION :
    - CODE_ARRAY_OPERAND( E, ANON, CONTEXT_TYPE ) normalise litteral / tranche / agregat / composant
      inline (DN_SELECTED, DN_INDEXED, DN_ALL) / expression en @DOUBLET -- avec, pour le composant,
      la re-emission des bornes au perimetre du commit 3 (litteral, constante, nombre nomme ; bruyant
      sinon).  C'est exactement le service manquant de COMPILE_ARRAY_VAR : on l'exporte au lieu de le
      dupliquer (piege n 57).

      que la tranche (commit 6) : __u := info du doublet, longueur par LId, CO_VAR, BLKMOV.
      Cas CONTRAINT : emission historique conservee a l'octet pres.

  ORACLE :

       (classifieur v2 : l'entree FIX_PRE disparait).
