=======================================================================================================================
LOT "STATOFS algn" — ALIGNEMENT PAR COMPOSANT (21332 -> 21328 sur GRMR)
=======================================================================================================================

Principe : l'alignement pertinent d'un champ est celui de son COMPOSANT
elementaire (1/2/4/8 octets), pas sa taille totale. L'expander le connait et
le passe en 3e parametre ; la macro garde l'ancienne regle par taille quand le
parametre est absent (algn:0), pour compatibilite avec tout FINC non regenere.


-----------------------------------------------------------------------------------------------------------------------
BLOC A — codi_x86_64.finc : remplacer la macro STATOFS
-----------------------------------------------------------------------------------------------------------------------

;			-------------------
macro			STATOFS	name, siz, algn:0			; Definition de l'offset statique (pour	un record	statique,	dans une virtual at	0)
;			-------------------
; algn = alignement du COMPOSANT elementaire en octets (1/2/4/8), passe par
; l'expander. algn 0 : compatibilite, ancienne regle par taille totale.
  if algn = 8
    align_q
  else if	algn = 4
    align_d
  else if	algn = 2
    align_w
  else if	algn = 1
								; octets : pas d'alignement
  else								; algn 0 : ancienne regle
    if siz > 4
      align_q
    else if	siz > 2
      align_d
    else if	siz > 1
      align_w
    end if
  end if
name = $								; nom offset du champ
  rb siz								; reservation
end macro


-----------------------------------------------------------------------------------------------------------------------
BLOC B — types_decls : fonction STATIC_TYPE_ALIGN_BYTES
-----------------------------------------------------------------------------------------------------------------------

B1. Spec, a coller apres "function STATIC_TYPE_SIZE_BITS ( T :TREE ) return NATURAL;" (~l.958) :

    function  STATIC_TYPE_ALIGN_BYTES	( T :TREE )	return NATURAL;		--| alignement du composant elementaire : 1/2/4/8

B2. Corps, a coller apres le corps de STATIC_TYPE_SIZE_BITS (~l.1348) :

			------------------------
    function		STATIC_TYPE_ALIGN_BYTES	( T : TREE )	return NATURAL
    is			-----------------------
    -- Alignement naturel du composant ELEMENTAIRE d'un type, en octets.
    -- Scalaire : la taille de son conteneur. Tableau : l'alignement de son
    -- composant (recursif : tableau de tableaux d'octets -> 1). Record,
    -- access, inconnu : 8, conservateur (= comportement STATOFS historique).
      TS	: TREE	:= FULL_TYPE_VIEW( T );
    begin
      if  TS = TREE_VOID  or else  TS = TREE_NIL  then
        return 8;
      end if;

      if  TS.TY = DN_INTEGER  or else  TS.TY = DN_ENUMERATION  or else  TS.TY = DN_FIXED  then
        case  OPER_SIZ_CHAR( TS )  is
	when 'b'	=>  return 1;
	when 'w'	=>  return 2;
	when 'd'	=>  return 4;
	when others	=>  return 8;
        end case;
      end if;

      if  TS.TY = DN_ARRAY  then
        return  STATIC_TYPE_ALIGN_BYTES( D( SM_COMP_TYPE, TS ) );
      end if;

      return 8;								-- DN_FLOAT, DN_ACCESS, DN_RECORD, autres

    end	STATIC_TYPE_ALIGN_BYTES;
	-----------------------

Filet : les seules differences admises sont (a) le 3e argument sur chaque
STATOFS, (b) des offsets/tailles REDUITS dans les records contenant des
tableaux d'octets ou de words. Aucun offset ne doit AUGMENTER.

size 21328 — l'ecart est tombe de 6 a 2 (le padding de NTER_LAST) mais
l'unification STATIC_SIZE / size=$ demeure necessaire pour le stride des
tableaux de records.
