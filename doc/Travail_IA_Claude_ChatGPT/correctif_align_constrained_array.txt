=======================================================================================================================
CORRECTIF STATIC_TYPE_ALIGN_BYTES — TABLEAUX CONTRAINTS (DN_CONSTRAINED_ARRAY)
=======================================================================================================================

Cause : un tableau contraint est DN_CONSTRAINED_ARRAY (dispatch de
CODE_TYPE_DECL, l.45), pas DN_ARRAY ; et SM_COMP_TYPE se lit sur la BASE du
spec (idiome PROCESS_CONSTRAINED_ARRAY, l.555). La branche tableau ne
s'allumait jamais -> return 8 conservateur -> layout identique a l'ancien
(21332), ce qui explique le READ de 21332 apres reconstruction complete.

CHERCHER (dans STATIC_TYPE_ALIGN_BYTES) :

      if  TS.TY = DN_ARRAY  then
        return  STATIC_TYPE_ALIGN_BYTES( D( SM_COMP_TYPE, TS ) );
      end if;

REMPLACER :

      if  TS.TY = DN_CONSTRAINED_ARRAY  or else  TS.TY = DN_ARRAY  then
        declare
	BASE	: TREE	:= D( SM_BASE_TYPE, TS );				-- SM_COMP_TYPE vit sur la BASE
        begin									-- (idiome l.555)
	if  BASE = TREE_VOID  or else  BASE = TREE_NIL  then
	  BASE := TS;
	end if;
	return  STATIC_TYPE_ALIGN_BYTES( D( SM_COMP_TYPE, BASE ) );
        end;
      end if;

(FULL_TYPE_VIEW en tete de fonction depouille le composant prive au rebond ;
la recursion couvre les tableaux de tableaux.)
