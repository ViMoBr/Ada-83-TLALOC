PATCH codi_x86_64U.finc  --  correctif : touche d'effacement sur console serie
Base : le fichier issu du palier 3.

Symptome : sur console serie, "ligness" suivi de Retour arriere rend "ligness".
Cause    : le terminal emet DEL (0x7F), pas BS (0x08). Le pilote TerminalDxe
           d'EDK2 traduit DEL en ScanCode = SCAN_DELETE avec UnicodeChar = 0.
           SYS_GET_STR voyait donc UnicodeChar = 0 et ignorait la frappe, comme
           il ignore les fleches et les touches de fonction.
           Sur clavier PS2 ou USB, Retour arriere donne bien UnicodeChar = 8 :
           c'est pourquoi le defaut ne se voit que sur la console serie.
Correctif : normaliser les trois formes vers 8, dans UEFI_READ_KEY. SYS_GET_STR
           n'est pas touche, il garde son unique test "cmp ax,8". SYS_GET_CHAR
           en beneficie aussi, et rend desormais 8 comme le faisait ReadFile en
           mode brut sous Windows.

Deux retouches.

========================================================================================================
PATCH 1  --  constante du ScanCode
========================================================================================================
--- ANCRE (ne pas modifier, sert a se reperer) --------------------------------------------------------
WaitForEvent		= 0x60				; dans EFI_BOOT_SERVICES
--- BLOC A INSERER -----------------------------------------------------------------------------------
SCAN_DELETE		= 0x08				; ScanCode EFI_INPUT_KEY de la touche Suppr

========================================================================================================
PATCH 2  --  normalisation, en queue de UEFI_READ_KEY
========================================================================================================
Il faut aussi declarer les deux nouvelles etiquettes locales. Anciennement :

    local k_retry

devient :

    local k_retry, k_erase, k_done

Puis, en fin de macro :
--- BLOC A SUPPRIMER ---------------------------------------------------------------------------------
  db 0x0F, 0xB7, 0x05						; movzx eax,word [rip+UEFI_KEY+2]  UnicodeChar
  dd UEFI_KEY + 2 - ($ + 4)
end macro
--- BLOC A INSERER -----------------------------------------------------------------------------------
  db 0x0F, 0xB7, 0x05						; movzx eax,word [rip+UEFI_KEY+2]  UnicodeChar
  dd UEFI_KEY + 2 - ($ + 4)
			; NORMALISATION DE LA TOUCHE D'EFFACEMENT.
			; Selon la console, "Retour arriere" n'arrive pas sous la meme forme :
			;   clavier PS2/USB  -> UnicodeChar = 8 (CHAR_BACKSPACE)
			;   terminal serie   -> le terminal emet DEL (0x7F), et le pilote
			;                       TerminalDxe le traduit en ScanCode = SCAN_DELETE
			;                       avec UnicodeChar = 0, donc invisible pour nous.
			; On ramene les trois cas a 8, ce qui est aussi ce que rendait ReadFile
			; en mode brut sous Windows. SYS_GET_STR n'a plus qu'un seul test.
  db 0x66, 0x83, 0xF8, 0x7F					; cmp ax,0x7F		DEL
  db 0x0F, 0x84							; je k_erase
  dd k_erase - ($ + 4)
  db 0x66, 0x85, 0xC0						; test ax,ax
  db 0x0F, 0x85							; jnz k_done		caractere ordinaire
  dd k_done - ($ + 4)
  db 0x66, 0x83, 0x3D						; cmp word [rip+UEFI_KEY],SCAN_DELETE
  dd UEFI_KEY - ($ + 5)
  db SCAN_DELETE
  db 0x0F, 0x85							; jne k_done		AX = 0 : touche ignoree
  dd k_done - ($ + 4)
k_erase:
  db 0xB8, 8, 0, 0, 0						; mov eax,8
k_done:
end macro

CONTROLES

      Ligne : ligness<-

      "Bonjuor" + 3 effacements + "our le monde"   ->   Recu : Bonjour le monde
  Effacement au-dela du debut de ligne :
      "abc" + 5 effacements + "ADA 83"             ->   Recu : ADA 83
  GET_CHAR et DIS_BONJOUR : inchanges.
