CHANTIER 'VALUE -- 3 blocs : 1 dans _standrd.adb (runtime), 2 dans
expander-expressions.adb.

Perimetre etabli au recensement : le corpus n'emploie QUE
INTEGER'VALUE et LONG_INTEGER'VALUE sur du decimal signe produit par
PRINT_NUM (29 sites expander-expressions, idl.adb, types_decls x2).
INTG_SIZE = 8 : les deux types sont des qwords -- UNE seule primitive
runtime 64 bits sert les deux. Pas de 'VALUE d'enumere dans le corpus :
il RESTE un TROU nomme (dette consignee, les tables de CODE_IMAGE
attendent le jour venu).

Architecture : reciproque exacte de 'IMAGE -- primitive Ada cachee
dans _standrd (doctrine "codi = machine a pile, pas le runtime" :
zero macro codi, pas d'echange de sommet -- le lieu resultat passe
SOUS l'argument par un temporaire VAR).

			-------------
  function		INTEGER_VALUE	( S :STRING )	return LONG_INTEGER
  is			-------------
  -- Primitive Ada cachee de 'VALUE des ENTIERS, reciproque
  -- d'INTEGER_IMAGE.  Appelee par le code genere : CODE_VALUE empile
  -- le lieu resultat (qword), puis @doublet de la chaine (l'argument,
  -- deja empile par l'appelant de la forme appel).
  -- LRM 3.5.5, SOUS-ENSEMBLE : blancs de tete/queue, signe optionnel,
  -- chiffres decimaux, soulignes admis (position non verifiee) ;
  -- base et exposant NON instruits ; chaine illicite ->
  -- CONSTRAINT_ERROR ; depassement 64 bits non controle (les valeurs
  -- du bootstrap viennent de PRINT_NUM).
    I		: INTEGER		:= S'FIRST;
    N		: LONG_INTEGER	:= 0;
    NEGATIVE	: BOOLEAN		:= FALSE;
    SOME_DIGIT	: BOOLEAN		:= FALSE;
  begin
    while  I <= S'LAST  and then  S(I) = ' '  loop				-- blancs de tete
      I := I + 1;
    end loop;

    if  I <= S'LAST  and then  ( S(I) = '-'  or else  S(I) = '+' )  then
      NEGATIVE := S(I) = '-';
      I := I + 1;
    end if;

    -- Accumulation en NEGATIF pour couvrir LONG_INTEGER'FIRST
    -- (le motif d'INTEGER_IMAGE).
    while  I <= S'LAST
    and then  (    ( S(I) >= '0'  and then  S(I) <= '9' )
	   or else  ( S(I) = '_'  and then  SOME_DIGIT ) )  loop
      if  S(I) /= '_'  then
        N := N * 10 - LONG_INTEGER( CHARACTER'POS( S(I) ) - CHARACTER'POS('0') );
        SOME_DIGIT := TRUE;
      end if;
      I := I + 1;
    end loop;

    while  I <= S'LAST  and then  S(I) = ' '  loop				-- blancs de queue
      I := I + 1;
    end loop;

    if  not SOME_DIGIT  or else  I <= S'LAST  then				-- rien lu, ou reliquat illicite
      raise CONSTRAINT_ERROR;
    end if;

    if  NEGATIVE  then
      return  N;
    else
      return  -N;
    end if;

  end	INTEGER_VALUE;
	-------------

COLLER APRES :

		----------
    procedure	CODE_VALUE
    is		----------
    -- 'VALUE des ENTIERS : appel de la primitive cachee
    -- STANDARD.INTEGER_VALUE (reciproque de CODE_IMAGE ; une seule
    -- primitive 64 bits pour INTEGER et LONG_INTEGER, INTG_SIZE = 8).
    -- A l'entree, l'appelant (forme appel) a DEJA empile @doublet de
    -- la chaine ; le lieu resultat doit passer DESSOUS (convention
    -- fonction scalaire) : detour par un temporaire, codi n'a pas
    -- d'echange de sommet et n'en gagnera pas (machine a pile, pas
    -- le runtime).
      ARG_TMP	:constant STRING	:= "VALARG_" & NEW_LABEL;
      LVL_STR	:constant STRING	:= IMAGE( CODI.CUR_LEVEL );
      TS	: TREE		:= PREFIX_TYPE_SPEC;
    begin
      -- Meme depouillement que CODE_IMAGE : vues privees puis type de
      -- base ('VALUE est un attribut du type de base, LRM 3.5.5).
      while  TS /= TREE_VOID
      and then  ( TS.TY = DN_PRIVATE  or else  TS.TY = DN_L_PRIVATE )  loop
        TS := D( SM_TYPE_SPEC, TS );
      end loop;
      while  TS /= TREE_VOID
      and then  D( SM_BASE_TYPE, TS ) /= TREE_VOID
      and then  D( SM_BASE_TYPE, TS ) /= TS  loop
        TS := D( SM_BASE_TYPE, TS );
      end loop;

      if  TS /= TREE_VOID  and then  TS.TY = DN_INTEGER  then
        PUT_LINE( "VAR" & tab & ARG_TMP & ", q" );
        PUT_LINE( tab & "Sa  " & LVL_STR & ", " & ARG_TMP );			-- depiler @doublet chaine
        PUT( tab & "LI" & tab & '0' );
        if  CODI.DEBUG  then  PUT( tab50 & "; lieu resultat sur pile" );  end if;
        NEW_LINE;
        PUT_LINE( tab & "La  " & LVL_STR & ", " & ARG_TMP );			-- re-empiler @doublet
        PUT_LINE( tab & "CALL" & tab & "STANDARD. ,INTEGER_VALUE_L##" );		-- ATTENTION a ceci : changer avec STANDARD

      else
        -- Enumere (tables de CODE_IMAGE a parcourir en inverse) et
        -- prefixes non resolus : NON instruits -- pas de besoin corpus.
        TROU( "CODE_ATTRIBUTE 'VALUE prefixe non entier" );
      end if;

    end	CODE_VALUE;
	----------

NOTES
========================================================================
1. LE LABEL _L## : comme pour INTEGER_IMAGE_L11 et ENUM_IMAGE_L31
   (les lignes "ATTENTION a ceci"), le suffixe de INTEGER_VALUE n'est
   connu qu'apres regeneration de _STANDRD.FINC -- coller le bloc 1,
   regenerer, relever le label INTEGER_VALUE_Lnn dans le FINC, le
   reporter dans le bloc 2. Ordre de collage : 1, regeneration, 2, 3.

2. PROTOCOLE DE PILE (pourquoi le temporaire) : convention appel =
   lieu resultat empile AVANT les parametres (INTEGER_IMAGE recoit le
   doublet resultat de PREPARE_ARRAY_RETURN avant REP). Ici l'argument
   est deja au sommet quand CODE_ATTRIBUTE prend la main -- Sa/LI 0/La
   reconstruit l'ordre [lieu, @doublet] sans toucher a codi ni a la
   branche attribut de CODE_FUNCTION_CALL.

3. TEMOIN TROU_VAL1 (avant de crier victoire) :
     - aller-retour : INTEGER'VALUE( INTEGER'IMAGE( X ) ) = X pour
       X dans { 0, 42, -1, grand positif, grand negatif } ;
     - formes : "  123  ", "+7", "1_000" acceptees ;
     - LONG_INTEGER'VALUE sur un rationnel de PRINT_NUM realiste ;
     - chaine illicite ( "12X", "" ) -> CONSTRAINT_ERROR attrapee
       par handler (exercer le raise du runtime !).
4. ORACLES corpus : idl.adb et expander-expressions.adb re-expanses
   en STRICT -> zero TROU ; le FINC de DI montre, apres le CALL de
   PRINT_NUM : VAR VALARG_n / Sa / LI 0 / La / CALL
   STANDARD.INTEGER_VALUE_Lnn / Sd -result__ofs. Puis filet habituel
   + auto-compilation (le runtime a change : re-derouler depuis le
   compilateur de reference, meme consigne que pour HASH_SEARCH).
5. DETTE consignee : 'VALUE d'enumere = TROU nomme restant (aucun
   usage corpus ; implantation future = parcours inverse des triplets
   IMAGES, symetrique d'ENUM_IMAGE).
