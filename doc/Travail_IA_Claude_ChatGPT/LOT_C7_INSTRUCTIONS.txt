DIAGNOSTIC (lecture du FINC de l'oracle, INSTF1.FINC)
-----------------------------------------------------
Le segfault est au CODE_RETURN du modele BAND_L15, pas a l'epilogue du
wrapper. Chaine observee dans le FINC :

  1. Site d'appel (correct, deja cable) : l'appelant alloue un doublet
     anonyme + bloc info, pousse LVA lvl, ANON_disp comme slot resultat,
     CALL B3_L21, et relit a travers le slot laisse en pile (La / BLKMOV).
     Les trois formes du temoin (affectation, operande d'egalite, init de
     declaration) suivent uniformement ce protocole.

  2. Modele BAND_L15 (correct, deja cable) : son CODE_RETURN ecrit le
     data_ptr par  SIq 2, -result__ofs, 0  et BLKMOV le descripteur
     16 octets vers [[slot]+8] -- il ecrit A TRAVERS le slot recu.

  3. Wrapper B3_L21 (LE bug) : INSTANTIATION_SUBPROG_GENERIQUE pousse
     LI 0 comme << lieu result >> du modele (declarations.adb:2105).
     BAND ecrit donc son data_ptr a l'adresse 0 -> segfault.
     Le protocole scalaire (LI 0 factice, valeur rapatriee apres CALL
     par S<c> lvl,-result__ofs) ne se transpose pas : un resultat
     doublet se materialise PAR le corps, A TRAVERS le slot.

CORRECTIF (une seule idee) : quand le resultat est DN_ARRAY, le wrapper
RELAIE son propre slot recu ( La lvl, -result__ofs ) au lieu de LI 0.
Le modele ecrit alors directement chez l'appelant ; l'epilogue du
wrapper n'a RIEN a rapatrier -- le TROU de la ligne 2364 se solde en
rameau INTENTIONNEL. Doctrine n 122 : on ne benit que DN_ARRAY
(l'observe : 10 traversees corpus, toutes DN_ARRAY) ; record/access non
contraints restent sous TROU, message discrimine.

Conventions : tabulations REELLES dans les blocs ci-dessous ; les
lignes ANCRE ne sont PAS modifiees ; SUPPRIMER designe le bloc
immediatement sous l'ancre.

NOTES AU CARNET (pas de code -- constats de lecture, hors perimetre C7)
========================================================================
N1. Modele generique SANS parametre Ada : NO_SUBP_PARAMS reste TRUE
    (CODE_PARAM_S l.148 teste la seule liste Ada) alors que PRMS emet
    GFP_ofs + result__ofs ; l'epilogue (structures.adb:397) emet donc un
    RTD nu qui laisse [slot, GFP] en pile, GFP AU SOMMET. Inoffensif
    ici : le wrapper enchaine UNLINK (relais C7) ou n'est jamais dans ce
    cas. MORDRAIT une fonction generique SCALAIRE sans parametre : le
    rapatriement S<c> lvl,-result__ofs du wrapper prendrait le GFP pour
    le resultat. Non exerce par le corpus ; a outiller par temoin AVANT
    tout correctif (discipline n 114/115).
N2. Les deux autres temoins du modele unique (ORACLES_TESTS, section C7 :
    fonction ORDINAIRE retournant tableau a bornes dynamiques ; temoin
    negatif return TAB2D(I)) restent dus -- le CODE_RETURN DN_ARRAY est
    atteste ici via BAND, mais seulement en 1 dimension et bornes
    d'instance (dette D6 a l'oeil).
N3. UNLINK restaure r13 (frame co-pile) sans jamais redescendre r14
    (sommet) : les data promues survivent par construction... et tout le
    reste aussi. Croissance monotone de la co-pile = choix assume
    << promue >>, a garder en tete pour les boucles longues.
