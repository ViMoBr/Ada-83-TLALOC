CHASSE AUX ECRIVAINS DE use__info -- methode systematique
Principe : le SEUL ecrivain de __u au monde est l'expander (19 sites, recenses ci-dessous). Les 20 FINC ne
sont que ses empreintes. On classe d'abord les empreintes (VIVANT / MORT) avec le script, puis la table
des signatures designe l'emetteur de chaque VIVANT, puis on corrige l'emetteur avec la recette etablie.
Etat acquis : SIGSEGV OPEN = donnee "././" (le LITTERAL en zone statique, suivi de ses cellules pointeurs
0xD9E8xx -- visibles dans votre dump pile) + info en bruit -> l'operande GAUCHE du "&" (PATH_TEXTE) arrive
avec un __u au patron ; LEN_G ~ 4,2 Mo ; le "&" recopie la zone statique ; l'OPEN copie le resultat.
========================================================================================================================

ETAPE 1 -- CLASSIFIEUR (script pret a l'emploi, a lancer dans le repertoire des FINC)

#!/bin/bash
# classe_use_info.sh -- classe chaque 'La ..., STANDARD._STRING.use__info' en MORT (dead store,
# __u re-ecrit dans les 25 lignes qui suivent) ou VIVANT (le doublet garde le patron).
for f in *.FINC ; do
  grep -n "STANDARD\._STRING\.use__info" "$f" | while IFS=: read -r ln _ ; do
    tgt=$(sed -n "$((ln+1))p" "$f" | sed -n 's/.*Sa[ \t]*[0-9]*,[ \t]*\([A-Za-z0-9_.]*__u\).*/\1/p')
    if [ -z "$tgt" ] ; then
      echo "$f:$ln: ??? (pas de Sa __u juste apres -- lecteur ou forme inattendue) :"
      sed -n "$((ln-3)),$((ln+3))p" "$f" | sed 's/^/    /'
      continue
    fi
    if sed -n "$((ln+2)),$((ln+25))p" "$f" | grep -q "Sa[ \t]*[0-9]*,[ \t]*$tgt" ; then
      echo "$f:$ln: MORT  ($tgt re-ecrit ensuite -- classe B, benin)"
    else
      echo "$f:$ln: VIVANT ($tgt garde le patron) :"
      sed -n "$((ln-8)),$((ln+4))p" "$f" | sed 's/^/    /'
    fi
  done
done

Sortie attendue : une poignee de VIVANTS parmi les 20 fichiers. Le contexte imprime (VAR SELARG_*,
"; array info ptr at __u", ANON_*, "__dat", "; var elab X") designe l'emetteur via la table ETAPE 2.
NB : elargir ensuite le meme grep aux AUTRES bases non contraintes du corpus si besoin
("STANDARD\._[A-Z_]*\.use__info" filtre sur les types DN_ARRAY de _STANDRD).

ETAPE 3 -- MARCHE A SUIVRE
  1. Lancer le classifieur. Les MORTS : les ignorer (ce sont les pre-inits ecrasees, classe B).
  2. Pour chaque VIVANT : la signature -> l'emetteur (table). M'envoyer les occurrences VIVANTES avec
     leur contexte imprime, PLUS les declarations Ada exactes de PATH_TEXTE et NOM_TEXTE (et l'unite
     qui les porte). Pari motive par le dump pile (data = le litteral "././" de la zone constante) :
     PATH_TEXTE est un objet de type NON CONTRAINT dont l'init passe par une branche qui ne re-pointe
     pas __u (tranche / composant / qualifie), ou un actual INDARG -- suspects 1 et 2 de la table.
  3. Je livre alors le(s) correctif(s) au format habituel -- meme recette que les commits 1-5 :
     jamais le patron dans un __u d'objet/actual/resultat ; bloc elabore (_<obj>__type, _<comp>__type,
     _<TYPE>) ou bloc ANON rempli ; refus BRUYANT pour les formes hors perimetre.
  4. Ajouter au temoin la forme identifiee (elle manquait par definition) AVANT d'appliquer le
     correctif : rouge d'abord, vert apres -- c'est la preuve.

ETAPE 4 -- LE CHANTIER QUI ETEINT LA FAMILLE (apres l'incendie)
  Centraliser l'emission dans UTILS : une procedure unique CODI.PUT_USE_INFO_REF( TYPE_SPEC, CONTEXTE )
  qui implemente TOUTE la discrimination (nomme -> chemin REGIONS_PATH ; objet anonyme -> _<obj>__type ;
  composant anonyme -> _<comp>__type ; NON CONTRAINT -> refus BRUYANT sauf contexte "vue formelle"
  explicite), puis migrer les 19 sites dessus, un temoin par migration. Le grep '_STRING.use__info'
  d'un FINC devient alors un ORACLE PERMANENT du filet : patron de _STANDRD + formels, rien d'autre.
  (Meme philosophie que TYPE_INFO_STR / piege n 99 : "toute fabrication manuelle est un bug en attente".)
