LIVRAISON : synchronisation codi_arm64.finc <-> codi_x86_64.finc (reference)
Date : 24 aout 2026

CONVENTIONS
  - ANCRE      : ligne(s) existante(s), inchangee(s), dont la suite est unique dans le fichier ;
                 chaque ligne d'ancre se compare ENTIERE (tabulations comprises).
  - SUPPRIMER  : bloc de lignes qui suit IMMEDIATEMENT l'ancre. Vide = insertion pure.
  - REMPLACER  : bloc mis a la place du bloc supprime. Vide = suppression pure.
  - Les tabulations sont reelles dans ce fichier. Ancres et blocs REMPLACER sont ASCII pur ;
    seuls cinq blocs SUPPRIMER du commit 3 contiennent, par necessite, les caracteres
    non ASCII qu'ils retirent (fleche, e accentue, tirets cadratins).
  - Les modifications d'un meme fichier s'appliquent dans l'ordre donne (les ancres
    ont ete verifiees uniques APRES application des modifications precedentes).
  - Un delimiteur >>>> / <<<< encadre chaque bloc ; il ne fait pas partie du texte.

ORACLE 1 (a executer AVANT le commit) : micro-source fasmg, cible arm64
  ---- test_c1.asm ----
  include 'codi_arm64.finc'
  PRO T
  PRMS
  PRM P_ofs
  endPRMS
  ELB 1
    VAR X_disp, q
    VAR Y_disp, b
    LIF 2.5
    CVTFI
    SQ 1, X_disp
    LI 0
    LI 0
    LI 0
    LI 0
    LEXCMP 1, 0
    RTD prm_siz
  endPRO
  SYS_EXIT
  ---------------------
  1. Avant patch : fasmg test_c1.asm t.bin DOIT echouer ou produire un binaire dont la
     VARzone de T avale le code (VAR sans end virtual) ; apres patch : assemblage propre.
  2. Apres patch, dans t.bin : le mot 9E 78 00 00 (LE : 00 00 78 9E) est present
     (fcvtzs x0, d0) et 9E F8 00 00 absent ; le mot EB 03 00 42 (LE : 42 00 03 EB) present,
     CB 03 00 42 absent. Verification : objdump -D -b binary -m aarch64 t.bin | grep -E 'fcvtzs|subs'
     -> 'fcvtzs x0, d0' et 'subs x2, x2, x3'.
  3. Si fasmg rejette 'load bits : qword from 0' (mod 1.4), revenir a la forme sans
     deux-points ; c'est la seule modification a valeur de tentative dans ce commit.
  4. Temoin de regle du prefixe (LRM 4.5.2) des que le runtime arm64 tourne :
     "ab" < "abc" et "abc" > "ab" (avant patch : resultat dependant des drapeaux du
     dernier cmp, donc faux sur au moins un des deux).

>>>>
macro			LI	val				; Load Integer (32 bits etendu signe vers 64)
;			-------------
;	Sur x86-64 c'etait : mov rax, val (5 octets imm32 + sign-extend automatique).
;	Sur ARM64, on utilise jusqu'a 4 instructions movz/movk si necessaire ; 
;	la macro QUAD_CONST optimise les chunks nuls. Pour les valeurs negatives
;	en imm32, on materialise les bits effectifs apres extension de signe vers 64.
;  local v64

;    v64 = val and 0xFFFFFFFFFFFFFFFF					; extension de signe vers 64 bits
;  else
;    v64 = val
;  end if
<<<<

>>>>
macro			LI	val				; Load Integer
;			-------------
;	Sur x86-64 : movabs rax, imm64 (dq val). Sur ARM64 : jusqu'a 4 movz/movk,
;	QUAD_CONST saute les chunks nuls ; val est un entier 64 bits signe, comme sur x86.
<<<<
