=======================================================================================================================
CORRECTIF v2 — T'IMAGE SUR FORMEL GENERIQUE : LE SLOT __u DU CONTRAT GFP
(remplace le correctif "resolution F-4a", architecturalement faux : corps PARTAGE)
=======================================================================================================================

Constat : le corps generique est compile UNE fois (IN_GENERIC_BODY) et accede
a tout ce qui concerne T via le cadre GFP (__ld/__st/__inadr/__outadr). La
table F-4a n'est pas remplie a ce moment — et une resolution statique reussie
aurait soude le PREMIER actuel dans un corps partage par toutes les
instanciations. La table d'images doit voyager PAR LE CADRE. Le commentaire
du contrat (declarations ~1760 : "PRM: __u(8) __ld(16) __st(24)") prevoyait
deja le slot __u ; il n'etait pas emis. On le complete.

Convention du slot __u : use__info de l'ACTUEL (le pointeur que la branche
statique de CODE_IMAGE charge par La lvl, path.use__info) si l'actuel est un
enumere ; 0 sinon (actuel entier, legal pour "type T is (<>)"). Le corps
teste a l'execution et retombe INTEGER_IMAGE.

-----------------------------------------------------------------------------------------------------------------------
BLOC A — declarations.adb, ACTUAL_GENERIC_TYPE, branche scalaire :
         a coller juste APRES le bloc __ld_ofs (ordre du contrat : __u dernier)
-----------------------------------------------------------------------------------------------------------------------

	    -- __u : use__info de l'ACTUEL, pour les attributs a table d'images
	    -- dans le corps partage ('IMAGE ; contrat ~1760, piege a35502r).
	    -- L'attribut est celui du type de BASE (LRM 3.5.5) : depouiller
	    -- et monter comme le fait la branche statique de CODE_IMAGE.
	    PUT_LINE( "VAR " & FORMAL_STR & "__u_ofs, q" );
	    declare
	      TS_ACT	: TREE	:= DEFN_TYPE_SPEC;
	    begin
	      while  TS_ACT /= TREE_VOID
	        and then  ( TS_ACT.TY = DN_PRIVATE  or else  TS_ACT.TY = DN_L_PRIVATE )  loop
	        TS_ACT := D( SM_TYPE_SPEC, TS_ACT );
	      end loop;
	      while  TS_ACT /= TREE_VOID
	        and then  D( SM_BASE_TYPE, TS_ACT ) /= TREE_VOID
	        and then  D( SM_BASE_TYPE, TS_ACT ) /= TS_ACT  loop
	        TS_ACT := D( SM_BASE_TYPE, TS_ACT );
	      end loop;

	      if  TS_ACT /= TREE_VOID
	      and then  TS_ACT.TY = DN_ENUMERATION
	      and then  D( XD_SOURCE_NAME, TS_ACT ) /= TREE_VOID
	      then
	        declare
		TN	: TREE	:= D( XD_SOURCE_NAME, TS_ACT );
	        begin
		PUT( tab & "La " & IMAGE( DI( CD_LEVEL, TS_ACT ) ) & ", " );
		CODI.REGIONS_PATH( TN );
		PUT_LINE( '_' & PRINT_NAME( D( LX_SYMREP, TN ) ) & ".use__info" );
	        end;
	      else
	        PUT_LINE( tab & "LI 0" );					-- actuel entier : marqueur nul
	      end if;
	    end;
	    PUT_LINE( tab & "Sa" & tab & LVL_STR & ", " & FORMAL_STR & "__u_ofs" );


-----------------------------------------------------------------------------------------------------------------------
BLOC B — expressions.adb, CODE_IMAGE : branche FORMEL avant la branche statique
-----------------------------------------------------------------------------------------------------------------------

Inserer, apres le depouillage/montee a la base et AVANT le "if TS /= TREE_VOID
and then TS.TY = DN_ENUMERATION ..." existant, une premiere branche :

        if  CODI.IN_GENERIC_BODY
        and then  TS /= TREE_VOID
        and then  D( XD_SOURCE_NAME, TS ) /= TREE_VOID
        and then  IS_GENERIC_FORMAL_TYPE( D( XD_SOURCE_NAME, TS ) )
        then
        -- FORMEL GENERIQUE (corps partage) : l'actuel est inconnu ici.
        -- Charger le use__info de l'actuel depuis le cadre (slot __u du
        -- contrat, pose par l'instanciation) ; nul => actuel entier,
        -- retombee INTEGER_IMAGE a l'EXECUTION.
          declare
	  FORMAL_STR	:constant STRING	:= PRINT_NAME( D( LX_SYMREP, D( XD_SOURCE_NAME, TS ) ) );
	  LBL		: LABEL_TYPE	:= NEW_LABEL;
          begin
	  PUT_LINE( tab & "La " & IMAGE( GENERIC_BASE_LEVEL+1 ) & ',' & tab & "-GFP_ofs" );
	  PUT_LINE( tab & "La , -" & FORMAL_STR & "__u_ofs" );
	  PUT_LINE( tab & "DUP" );
	  PUT_LINE( tab & "LI 0" );
	  PUT_LINE( tab & "CEQ" );
	  PUT_LINE( tab & "BT" & tab & "img_int_" & LABEL_STR( LBL ) );
	  PUT_LINE( tab & "LI" & tab & "16" );
	  PUT_LINE( tab & "ADD" );
	  PUT_LINE( tab & "CALL" & tab & "STANDARD. ,ENUM_IMAGE_L31" );				-- ATTENTION : suivre STANDARD
	  PUT_LINE( tab & "BRA" & tab & "img_end_" & LABEL_STR( LBL ) );
	  PUT_LINE( "img_int_" & LABEL_STR( LBL ) & ':' );
	  PUT_LINE( tab & "DROP" );							-- jeter le pointeur nul
	  PUT_LINE( tab & "CALL" & tab & "STANDARD. ,INTEGER_IMAGE_L11" );			-- ATTENTION : suivre STANDARD
	  PUT_LINE( "img_end_" & LABEL_STR( LBL ) & ':' );
          end;

        elsif  <branche enumere statique existante, INCHANGEE>
        ...

Pile : l'appelant a deja empile [descripteur, REP] (convention existante).
Branche enum : + IMAGES => ENUM_IMAGE( REP, IMAGES ). Branche entiere : DROP
du pointeur nul => INTEGER_IMAGE( valeur ). Equilibre garanti dans les 2 cas.

ADAPTATIONS LOCALES (memes idiomes maison, orthographes a suivre sur place) :
- GENERIC_BASE_LEVEL et l'acces "La <n>, -GFP_ofs / La , -X_ofs" : copier le
  site declarations ~442 (acces __st depuis le corps) ;
- LBL/NEW_LABEL/LABEL_STR : idiome de CODE_IF (instructions ~222) ;
- CEQ : l'operateur d'egalite qu'emet CODE_EQ, si son nom differe.

  le slot __u fraichement pose sert tel quel ;

  STATIQUE sur un formel dans un corps partage est suspecte ; l'information
