CE QUE LE SITE print_nod REVELE
-------------------------------
    DUMMY2 : INTEGER;
    DUMMY  : array( 1 .. 4 ) of CHARACTER := (CHARACTER'VAL(1), NUL...);
    for DUMMY use at DUMMY2'ADDRESS;
L'idiome de DETECTION D'ENDIANITE : l'ELABORATION ecrit (1,0,0,0) a
travers l'overlay, puis le code relit DUMMY2. Deux dimensions hors du
motif v2, d'un coup :

1. SORTES ASYMETRIQUES. L'equation  X_disp = Y_disp  n'est juste que si
   les DEUX slots portent la meme chose : valeur/valeur (scalaire sur
   scalaire) ou data_ptr/data_ptr (composite sur composite). Ici le
   slot de DUMMY2 porte sa VALEUR : l'equation ferait DEREFERENCER
   << 1 >> comme adresse. Le bon geste : DUMMY garde son VAR _disp, et
   data_ptr := ADRESSE du slot cible --  LVA lvl, DUMMY2_disp ;
   Sa lvl, DUMMY_disp . (Le reciproque -- SCALAIRE sur composite --
   reste impossible sans indirection d'acces scalaire : TROU, et le
   v2 le laissait passer a tort -- delta D1 ci-dessous le ferme.)

2. INIT A TRAVERS L'OVERLAY. LRM 13.5 : l'elaboration de l'objet ECRIT
   l'emplacement vise -- c'est le BUT de l'idiome. Pour un agregat
   contraint : pas de COVAR_ALLOCATE, puis  La lvl, _disp  +
   CODE_AGGREGATE, la machinerie existante ecrit chez la cible. Les
   autres formes d'init restent TROU (un litteral chaine RE-POINTERAIT
   _disp sur la constante : il aliaserait la CONSTANTE, pas la cible).

Grille des sortes apres v2.1 (cible en colonnes) :
                 scalaire        composite       autre/dynamique
  scalaire       EQUATION        TROU (D1)       TROU
  array          LVA @slot (D2-5) EQUATION       TROU
  record         TROU            EQUATION (D6)   TROU
Init : permise pour ARRAY par AGREGAT seulement ; TROU ailleurs.

Conventions : tabulations REELLES ; ANCRE inchangee ; SUPPRIMER = bloc
sous l'ancre. La 1re ligne de chaque bloc SUPPRIMER sert d'ancre quand
elle est REPRISE en tete du remplacement.

        OVERLAY_TGT_TYPE	: TREE			:= TREE_VOID;					-- vue complete du type de la cible (posee en tete de corps)
        OVERLAY_EQUATE	: BOOLEAN			:= FALSE;					-- cible COMPOSITE : equation, cellule data_ptr PARTAGEE

--- D3 --- COMPILE_ARRAY_VAR, tete de corps : calcul des sortes

ANCRE (unique, inchangee -- rien a supprimer, INSERER dessous) :
      end UNCONSTRAINED_AGGREGATE_OBJECT;
	------------------------------

      begin

INSERER SOUS L'ANCRE :
        if  OVERLAY_TGT /= TREE_VOID  then								-- C8 : la SORTE de la cible choisit le mecanisme
	OVERLAY_TGT_TYPE := CODI.FULL_TYPE_VIEW( D( SM_OBJ_TYPE, OVERLAY_TGT ) );
	OVERLAY_EQUATE   := OVERLAY_TGT_TYPE.TY = DN_ARRAY   or else  OVERLAY_TGT_TYPE.TY = DN_CONSTRAINED_ARRAY
		     or else  OVERLAY_TGT_TYPE.TY = DN_RECORD  or else  OVERLAY_TGT_TYPE.TY = DN_CONSTRAINED_RECORD;
	OVERLAY_LVA      := OVERLAY_TGT_TYPE.TY in CLASS_SCALAR;
	DO_OVERLAY       := OVERLAY_EQUATE  or else  OVERLAY_LVA;
        end if;
