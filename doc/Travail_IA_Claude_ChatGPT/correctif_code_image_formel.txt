=======================================================================================================================
CORRECTIF CODE_IMAGE — PREFIXE = TYPE FORMEL GENERIQUE (a35502r)
=======================================================================================================================

Cause : T'IMAGE avec T formel discret. Le spec du formel (DN_ENUMERATION du
gabarit) n'a jamais ete compile : CD_LEVEL non pose. La branche enumere de
CODE_IMAGE exige un type statiquement connu. Le corps etant compile a
l'instanciation, la table F-4a contient formel -> spec de l'ACTUEL ; c'est
deja l'idiome du site expressions ~1650 pour un autre attribut.

CHERCHER (tete de CODE_IMAGE) :

      declare
        TS	: TREE	:= PREFIX_TYPE_SPEC;
      begin
      -- Depouiller les vues privees et remonter au type de BASE :

REMPLACER :

      declare
        TS	: TREE	:= PREFIX_TYPE_SPEC;
        ACTUAL	: TREE	:= TREE_VOID;
      begin
      -- F-4a : prefixe = type FORMEL generique (T'IMAGE dans un corps
      -- instancie, a35502r). Le spec du formel n'est pas un type compile
      -- (CD_LEVEL non pose) : resoudre vers le spec de l'ACTUEL via la
      -- table de l'instanciation courante — meme idiome que le site
      -- GENERIC_ACTUAL_TYPE_OF des autres attributs. La resolution precede
      -- le depouillage : l'actuel peut lui-meme etre prive ou sous-type.
        if  PREFIX_NAME /= TREE_VOID  and then  PREFIX_NAME /= TREE_NIL  then
          ACTUAL := CODI.GENERIC_ACTUAL_TYPE_OF( PRINT_NAME( D( LX_SYMREP, PREFIX_NAME ) ) );
          if  ACTUAL /= TREE_VOID  then
	  TS := ACTUAL;
          end if;
        end if;
      -- Depouiller les vues privees et remonter au type de BASE :

(le reste de CODE_IMAGE est INCHANGE : depouillage, montee a la base, branche
enumere avec CD_LEVEL/REGIONS_PATH/use__info+16, retombees existantes)

NOTE 1 : si l'identifiant PREFIX_NAME n'est pas visible depuis CODE_IMAGE,
prendre le nom par le spec lui-meme :
          ACTUAL := CODI.GENERIC_ACTUAL_TYPE_OF(
			PRINT_NAME( D( LX_SYMREP, D( XD_SOURCE_NAME, TS ) ) ) );
(le XD_SOURCE_NAME du spec formel est le TYPE_ID "T" — la cle de la table),
garde par XD_SOURCE_NAME /= VOID/NIL.

NOTE 2 : limite assumee — si un jour un prefixe formel arrive SANS entree
dans la table (corps compile hors instanciation), l'ancien message reapparait
et pointe ici. Pas de garde supplementaire : CD_COMPILED/CD_LEVEL non poses
ne sont pas testables proprement tant que D cause au lieu de lever (PIEGES).

ORACLE (a35502r) :
- Plus de message "!! L ATTRIBUT CD_LEVEL..." ;
- la sequence T'IMAGE emet La <niveau de COLOR>, ..._COLOR.use__info,
  LI 16, ADD, CALL ENUM_IMAGE : la table d'images de l'ACTUEL ;
- le test s'execute (S1 = " BLUE"/"BLUE" selon la casse ACVC) et RESULT passe.

AUDIT DE VOISINAGE : le meme motif "branche enumere statique" existe-t-il
dans CODE_VALUE, 'WIDTH, ou tout autre attribut a table d'images ? a35502r
les exerce tous (WIDTH, POS, VAL, SUCC, PRED, VALUE, FIRST, LAST) : si un
seul autre message !! apparait dans A35502R.FINC, meme remede, meme table.
