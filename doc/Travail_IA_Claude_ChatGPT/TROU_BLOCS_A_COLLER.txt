			--^^^^--
  procedure		  TROU			( SITE :STRING; NOEUD :TREE := TREE_VOID )
  is			--------

	-- Signal maison des manques de capacite. Ecrit "; !! TROU ..."
	-- dans le FINC (traçabilite : grep TROU = inventaire vivant)
	-- ET le meme message sur la console (lecon n 96 : un
	-- commentaire FINC n'est vu par personne), puis leve
	-- PROGRAM_ERROR -- mode STRICT, defaut. En RECENSEMENT :
	-- compte, logue, continue.
	-- HYPOTHESE : la sortie courante est le FINC (vrai de tous les
	-- sites CODE_*). Si FS est ferme (hors expansion d'unite), on
	-- ecrit seulement sur la console.

    function  MSG					return STRING
    is
    begin
      if  NOEUD = TREE_VOID  then
        return  "!! TROU " & SITE;
      else
        return  "!! TROU " & SITE & " : " & NODE_NAME'IMAGE( NOEUD.TY );
      end if;
    end MSG;

  begin
    TROU_COUNT := TROU_COUNT + 1;

    if  IS_OPEN( FS )  then
      PUT_LINE( "; " & MSG );								-- dans le FINC (sortie courante)
      SET_OUTPUT( STANDARD_OUTPUT );
      PUT_LINE( MSG );									-- sur la console
      SET_OUTPUT( FS );									-- retour au FINC
    else
      PUT_LINE( MSG );									-- deja sur la console
    end if;

    if  not TROU_RECENSEMENT  then
      raise PROGRAM_ERROR;
    end if;

  end	TROU;
	----

NOTES DE LECTURE (rien a coller ci-dessous)
========================================================================

1. USAGE AUX SITES -- les deux formes canoniques :

   Dispatcher case :
       when others =>  TROU( "CODE_ATTRIBUTE", ATTRIBUTE );

   Chaine elsif sans else (le motif systemique du triage §1) :
       else
         TROU( "CODE_EXP", EXP );
       end if;

   Corps entierement vide (tasking, etc.) :
       begin
         TROU( "CODE_ACCEPT", ADA_ACCEPT );
       end;

   Sans noeud pertinent :
       TROU( "CODE_CONVERSION cible fixed->fixed small different" );

2. CONVENTION DE NOMMAGE DU SITE : le nom de la procedure englobante,
   en clair, eventuellement suffixe d'une precision -- c'est ce que
   rendra `grep TROU` et ce que montrera la console. Pas d'abreviation.

3. MODE RECENSEMENT : basculer TROU_RECENSEMENT := TRUE dans la spec
   (a cote de DEBUG), recompiler, expanser le corpus, collecter les
   lignes "!! TROU" de la console -- c'est la liste des trous VIVANTS,
   a consigner dans ETAT_PILIERS comme carnet de dettes. Puis remettre
   FALSE. Le FINC d'un run recensement ne doit JAMAIS etre assemble.

4. GARDE IS_OPEN( FS ) : couvre un TROU leve hors expansion d'unite
   (elaboration des predefinies, CREATE_FAS_MAIN_FILE...). Limite
   connue : si une autre sortie que FS est courante alors que FS est
   ouvert (cas CREATE_FAS_MAIN_FILE avec son fichier F propre), le
   retour SET_OUTPUT( FS ) serait inexact -- aucun site CODE_* n'est
   dans ce cas aujourd'hui ; a garder en tete si un TROU() etait un
   jour pose dans CREATE_FAS_MAIN_FILE.

5. LE RAISE EST NU (pas de parametre message, Ada 83) : le message est
   deja parti sur les deux canaux AVANT la levee -- l'ordre est
   volontaire, ne pas l'inverser.

6. PREMIER CANDIDAT D'ESSAI recommande avant deploiement en masse :
   le `when others => null;` de CODE_ATTRIBUTE (expressions:2902) --
   site avale-tout, facile a exercer avec un attribut exotique, et
   verdict TROU certain. Un oracle negatif (l'expansion DOIT lever)
   valide la mecanique complete : message FINC + message console +
   PROGRAM_ERROR + bilan CLOSE non atteint en mode STRICT.
