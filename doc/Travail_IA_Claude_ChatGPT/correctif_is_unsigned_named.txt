=======================================================================================================================
CORRECTIF IS_UNSIGNED_TYPE — GAMME DU PREMIER SOUS-TYPE NOMME (remplace le pas 0 de la phase 2)
=======================================================================================================================

Diagnostic (temoin TEST du 18/07, dump DIANA) : la SM_RANGE de la base anonyme
n'est PAS la gamme declaree mais celle du predéfini parent dont elle derive
(RM83 3.5.4) — [DN_RANGE,P10,L72] dans la region STANDRD, FST negatif. Le
predicat lisait cette gamme et rendait FALSE pour tout type.

Regle corrigee : le signe du conteneur se decide sur la gamme du PREMIER
SOUS-TYPE NOMME. Justification : aucun objet ne peut etre du type de base
anonyme, et tout sous-type nommable est contraint dans la gamme du premier
nomme — le conteneur ne recoit jamais d'autre valeur (apres range check).
Chemin DIANA : base -> XD_SOURCE_NAME (TYPE_ID de la declaration)
                    -> SM_TYPE_SPEC (spec nomme) -> SM_RANGE (gamme declaree).

expander-utils.adb, IS_UNSIGNED_TYPE : remplacer tout le bloc declare final

REMPLACER PAR :

    declare
      BASE	: TREE	:= FULL_VIEW( D( SM_BASE_TYPE, TS ) );
      NAMED	: TREE;
      RNG	: TREE;
      FST	: TREE;
    begin
      if  BASE = TREE_VOID  or else  BASE = TREE_NIL  then
        BASE := TS;
      end if;

      -- Gamme decisive : celle du PREMIER SOUS-TYPE NOMME, pas celle de la
      -- base anonyme (RM83 3.5.4 : la base herite de la gamme du predéfini
      -- parent — temoin DIANA du 18/07, SM_RANGE de la base en region STANDRD).
      -- Aucun objet n'est du type de base, et tout sous-type nommable est
      -- contraint dans la gamme du premier nomme : le conteneur ne recoit
      -- jamais d'autre valeur.
      NAMED := BASE;
      if       D( XD_SOURCE_NAME, BASE ) /= TREE_VOID
      and then D( XD_SOURCE_NAME, BASE ) /= TREE_NIL  then
        declare
	SPEC	: TREE	:= FULL_VIEW( D( SM_TYPE_SPEC, D( XD_SOURCE_NAME, BASE ) ) );
        begin
	if  SPEC /= TREE_VOID  and then  SPEC /= TREE_NIL  then
	  NAMED := SPEC;
	end if;
        end;
      end if;

      RNG := D( SM_RANGE, NAMED );
      if  RNG = TREE_VOID  or else  RNG = TREE_NIL  then
        RNG := D( SM_RANGE, TS );							-- repli : gamme du spec recu
      end if;

(la suite — garde VOID/NIL -> FALSE, deshabillage PARENTHESIZED/CONVERSION,
test DN_NUMERIC_LITERAL avec SM_VALUE >= 0 — est INCHANGEE)
