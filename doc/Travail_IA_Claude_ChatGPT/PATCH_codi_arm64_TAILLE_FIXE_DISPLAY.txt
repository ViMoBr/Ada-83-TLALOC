LIVRAISON : codi_arm64.finc -- lot "taille fixe des adresses" + "acces display/memoire"
==========================================================================================

Fichier cible : codi_arm64.finc DEJA PORTEUR du correctif BT/BF (livraison
precedente). Les numeros de ligne sont ceux du fichier tel que joint a la
premiere demande (2482 lignes) : les deux modifications BT/BF (lignes 1440-
1459) sont en aval de toutes celles-ci sauf CALL/CALLI, qu'elles decalent de
+5 lignes -- les ancres restent uniques, ne se fier qu'a elles.

Format : une modification = ANCRE (ligne existante unique, inchangee) + bloc
A SUPPRIMER (texte existant exact, commencant a la ligne qui suit l'ancre,
tabulations comprises) + bloc DE REMPLACEMENT. Tout le texte nouveau est
ASCII pur. Les blocs sont a copier, pas a retaper.

Objectif
--------
1. Contrat SIZE_OF = ENCODE (celui de TARGET_CODE x86) : aucune taille
   d'element ne depend d'une valeur inconnue en passe 1. Aujourd'hui
   QUAD_CONST choisit son nombre d'instructions selon les chunks nuls de la
   valeur, et elle est appelee sur des references avant (CALL/CALLI :
   'retour' ; LSPA : prefix#subname#_ ; LCA : ptr+disp). C'est aussi une
   decision de taille inter-passes non monotone (piege n. 88).
   -> CALL/CALLI : adr x16, .+16 (PC-relatif, 1 instruction, plus de label).
   -> LCA/LSPA : QUAD_ADDR, movz+movk de taille FIXE (assert < 4 Go).
   -> QUAD_CONST reste reservee aux immediats (valeur dans le texte, taille
      calculable au parse) et gagne des chemins rapides (1 instruction pour
      0..0xFFFF et -0x10000..-1, movn pour les negatifs).
2. Lignes interpretees par fasmg : FP_IN_RAX/RAX_IN_FP/FP_IN_RBP en encodage
   direct (1 ligne au lieu du passage par LOAD_QUAD, ~12 lignes) ; LOAD_QUAD,
   STORE_QUAD et les neuf FETCH_*/STORE_* sans symboles 'local'.

Piege decouvert au passage (a verser dans PIEGES.md)
----------------------------------------------------
fasmg substitue les parametres de macro TEXTUELLEMENT et ses operateurs
and/or/xor lient plus fort que + - *, shl/shr/mod encore plus fort (manuel
fasmg, section "Expressions"). Donc dans LOAD_QUAD appelee avec ofs = 8*lvl :
  (ofs mod 8) = 0  devient  8*(lvl mod 8) = 0   -> faux pour lvl = 1..7
  ofs shr 3        devient  8*(lvl shr 3)       -> 0 pour lvl = 1..7
Les 'local signed_ofs = ofs' des macros actuelles neutralisaient le second
piege sans le nommer ; le premier etait actif : FP_IN_RAX emettait un LDUR
(voie -256..255, correcte par chance) au lieu du LDR scale pour tout niveau
non multiple de 8. Regle : dans une macro, tout parametre utilise dans une
expression est ecrit (param). Ce lot l'applique partout ou il touche.

Contre-epreuve effectuee ici avec fasmg (binaire g.l8vn du depot officiel)
sur des temoins LLIR assembles avec l'ancien et le nouveau codi : le nouveau
assemble en autant ou moins de passes ; le diff des desassemblages ne montre
que les changements attendus ci-dessous ; 410 LI aleatoires 64 bits (dont
les bornes 0, -1, +-0x10000, 2^63, 2^64-1) rematerialisent la bonne valeur
avec le nombre minimal d'instructions ; les x17 des voies de repli (offsets
40000, -40000, -300, 70000, 8192...) sont exacts ; adr x16 vise bien
l'instruction qui suit le b / br.

Encodages nouveaux :
  0x10000090              adr x16, .+16
  0xD2800000 | imm<<5     movz Rd, #imm          0x92800000 | imm<<5  movn Rd, #imm
  0xF2A00000 | imm<<5     movk Rd, #imm, lsl #16
  0xF9400380 | lvl<<10    ldr x0,  [x28, #8*lvl]
  0xF940039D | lvl<<10    ldr x29, [x28, #8*lvl]
  0xF9000380 | lvl<<10    str x0,  [x28, #8*lvl]

Effet sur les octets emis (a connaitre pour l'oracle) :
  - LI/LIF de valeur 0..0xFFFF : inchanges. LI negatifs et grandes valeurs :
    plus courts (movn). Ex. LI -1 : 4 instructions -> 1.
  - LCA/LSPA : toujours exactement 2 instructions (au lieu de 1 a 3).
  - CALL : 16 octets fixes (adr, sub, str, b) ; CALLI : POP + 16 octets.
  - Display : ldr/str scales a la place des ldur/stur pour lvl non multiple
    de 8 (FP_IN_RAX, RAX_IN_FP, FP_IN_RBP, et les STORE_QUAD 8*lvl / LOAD_QUAD
    8*n de EXC_*). Meme semantique.
  - FETCH_*/STORE_*/LVA/LIVA : octets IDENTIQUES pour des arguments simples
    (nombres, symboles), ce qui est le cas de toute la LLIR emise.

MODIF 1.1 -- QUAD_CONST reecrite (chemins rapides, negatifs par movn, sans local) + nouvelle macro QUAD_ADDR de taille fixe
---------------------------------------------------------------------
ANCRE (ligne existante unique, inchangee) :
<<<
macro			QUAD_CONST	Rd, val
>>>
A SUPPRIMER (a partir de la ligne qui suit l'ancre, jusqu'a "end macro" inclus) :
<<<
;			...........................
;	Materialise une valeur 64 bits arbitraire dans Rd via movz/movk (4 instructions max).
;	Les chunks a zero sont sautes (sauf si tous nuls : un movz #0 minimum).
  local v, emitted, chunk
  v = val
  emitted = 0

  repeat 4, idx:0
    chunk = (v shr (16*idx)) and 0xFFFF
    if chunk <> 0
      if emitted = 0
        dd 0xD2800000  or  (idx shl 21)  or  (chunk shl 5)  or  Rd		; movz Rd, #chunk, lsl #(16*idx)
        emitted = 1
      else
        dd 0xF2800000  or  (idx shl 21)  or  (chunk shl 5)  or  Rd		; movk Rd, #chunk, lsl #(16*idx)
      end if
    end if
  end repeat

  if emitted = 0
    dd 0xD2800000  or  Rd						; movz Rd, #0
  end if
end macro
>>>

REMPLACEMENT :
<<<
;			...........................
;	Materialise une valeur entiere 64 bits (IMMEDIAT connu des la passe 1) dans Rd.
;	Chemins rapides : 0..0xFFFF -> movz ; -0x10000..-1 -> movn (une instruction).
;	Sinon, sur le motif 64 bits de val : vue movz (chunks nuls implicites) ou vue
;	movn (chunks 0xFFFF implicites), la moins chere ; premier chunk explicite par
;	movz/movn, les suivants par movk. Taille = max(1, min(nz, nf)) : fonction de
;	val seule, calculable au parse par TARGET_CODE (val est dans le texte).
;	Pour une ADRESSE (reference avant, valeur inconnue en passe 1) : QUAD_ADDR,
;	de taille fixe (contrat SIZE_OF = ENCODE, piege n. 88 : jamais de taille
;	dependant d'une valeur de la passe precedente).
;	Precedence fasmg : and/or/shl/shr/mod lient plus fort que + - * ; les parametres
;	de macro sont substitues TEXTUELLEMENT, d'ou les parentheses (val) partout.
  if (val) >= 0 & (val) <= 0xFFFF
    dd 0xD2800000  or  ((val) shl 5)  or  Rd					; movz Rd, #val
  else if (val) < 0 & (val) >= -0x10000
    dd 0x92800000  or  ((-(val) - 1) shl 5)  or  Rd				; movn Rd, #(not val)
  else
    local emitted, chunk, nz, nf
    nz = 0									; chunks non nuls   (cout de la vue movz+movk)
    nf = 0									; chunks /= 0xFFFF  (cout de la vue movn+movk)
    repeat 4, idx:0
      chunk = ((val) shr (16*idx)) and 0xFFFF
      if chunk <> 0
        nz = nz + 1
      end if
      if chunk <> 0xFFFF
        nf = nf + 1
      end if
    end repeat
    emitted = 0
    repeat 4, idx:0
      chunk = ((val) shr (16*idx)) and 0xFFFF
      if nz <= nf							; vue movz : les chunks nuls sont implicites
        if chunk <> 0
          if emitted = 0
            dd 0xD2800000  or  (idx shl 21)  or  (chunk shl 5)  or  Rd		; movz Rd, #chunk, lsl #(16*idx)
            emitted = 1
          else
            dd 0xF2800000  or  (idx shl 21)  or  (chunk shl 5)  or  Rd		; movk Rd, #chunk, lsl #(16*idx)
          end if
        end if
      else								; vue movn : les chunks 0xFFFF sont implicites
        if chunk <> 0xFFFF
          if emitted = 0
            dd 0x92800000  or  (idx shl 21)  or  ((chunk xor 0xFFFF) shl 5)  or  Rd	; movn Rd, #(not chunk), lsl #(16*idx)
            emitted = 1
          else
            dd 0xF2800000  or  (idx shl 21)  or  (chunk shl 5)  or  Rd		; movk Rd, #chunk, lsl #(16*idx)
          end if
        end if
      end if
    end repeat
    if emitted = 0							; tous les chunks implicites : 0 (vue movz) ou -1 (vue movn)
      if nz <= nf
        dd 0xD2800000  or  Rd							; movz Rd, #0
      else
        dd 0x92800000  or  Rd							; movn Rd, #0  (Rd = -1)
      end if
    end if
  end if
end macro

;			..........................
macro			QUAD_ADDR	Rd, val
;			..........................
;	Materialise une ADRESSE (symbole, reference avant possible) dans Rd.
;	TAILLE FIXE : movz + movk, 32 bits (image ELF chargee sous 4 Go, comme sur
;	x86-64 ou movabs est lui aussi de taille fixe). L'assert garde l'hypothese ;
;	si elle tombait un jour, passer a trois instructions (48 bits), toujours fixes.
  assert (val) >= 0 & (val) <= 0xFFFFFFFF
  dd 0xD2800000  or  (((val) and 0xFFFF) shl 5)  or  Rd				; movz Rd, #lo16
  dd 0xF2A00000  or  ((((val) shr 16) and 0xFFFF) shl 5)  or  Rd			; movk Rd, #hi16, lsl #16
end macro
>>>

MODIF 1.4 -- CALL : adresse de retour par adr (taille fixe, plus de label local)
---------------------------------------------------------------------
ANCRE (ligne existante unique, inchangee) :
<<<
macro			CALL	prefix, subname			; CALL par offset
>>>
A SUPPRIMER (a partir de la ligne qui suit l'ancre, jusqu'a "end macro" inclus) :
<<<
;			-------------------------
; AArch64 n'empile pas l'adresse de retour. Pour conserver EXACTEMENT le modele
; LLIR/x86, on gere explicitement la micro-pile par SP : chaque appel reserve
; 16 octets (alignement AArch64), range l'adresse de retour a [sp], puis branche.
; RTD depile cette adresse. Ainsi une restauration de SP par EXC_RAISE deroule
; aussi les retours des frames abandonnes, sans avoir a sauver x30 dans le contexte.
  postpone
    if ~definite prefix#subname#_
      prefix#subname#_ = prefix#subname#.elab
    end if
  end postpone

  local retour
  QUAD_CONST	16, retour
  dd 0xD10043FF							; sub sp, sp, #16
  dd 0xF90003F0							; str x16, [sp]
  BRA prefix#subname#_
retour:
end macro
>>>

REMPLACEMENT :
<<<
;			-------------------------
; AArch64 n'empile pas l'adresse de retour. Pour conserver EXACTEMENT le modele
; LLIR/x86, on gere explicitement la micro-pile par SP : chaque appel reserve
; 16 octets (alignement AArch64), range l'adresse de retour a [sp], puis branche.
; RTD depile cette adresse. Ainsi une restauration de SP par EXC_RAISE deroule
; aussi les retours des frames abandonnes, sans avoir a sauver x30 dans le contexte.
; L'adresse de retour est PC-relative (adr x16, .+16 : la 4e instruction apres
; l'adr) : taille fixe de 16 octets par CALL, aucun label, aucune dependance
; a une valeur de passe precedente (contrat SIZE_OF = ENCODE).
  postpone
    if ~definite prefix#subname#_
      prefix#subname#_ = prefix#subname#.elab
    end if
  end postpone

  dd 0x10000090							; adr x16, .+16	(adresse de retour = apres le b)
  dd 0xD10043FF							; sub sp, sp, #16
  dd 0xF90003F0							; str x16, [sp]
  BRA prefix#subname#_
end macro
>>>

ORACLE DU COMMIT 1
---------------------------------------------------------------------
O1.1 (bloquant) : assemblage du compilateur entier sans erreur ; nombre de
  passes <= 18 (attendu : inchange ou en baisse, jamais en hausse).
O1.2 (taille fixe) : desassembler l'executable (objdump -D -b binary
  -m aarch64) et verifier :
    - chaque "adr x16" est suivi de sub sp / str x16 / b (ou br x0) ;
    - grep "adr x16" | wc -l  =  nombre de CALL + CALLI de la LLIR ;
    - aucun movz/movk vers x0 en 3 ou 4 instructions dont la valeur soit
      une adresse de l'image (0x4xxxxx) : toutes en exactement 2.
O1.3 (non-regression) : ENUM_TEST, DIRECT_IO_TEST, SEQ_IO_TEST, temoins a
  entiers negatifs (LI -1, LI -100000, bornes 'FIRST de INTEGER) et flottants
  (LIF : 0.0, 1.0, -1.0, 1.0e300) : sorties octets identiques a avant.
O1.4 (auto-hebergement) : le compilateur assemble se recompile lui-meme et
  le second binaire est identique au premier.
O1.5 (temps) : chronometrer l'assemblage complet ; a reporter avec O2.5.

MODIF 2.1 -- LOAD_QUAD sans locals, parametres parentheses
---------------------------------------------------------------------
ANCRE (ligne existante unique, inchangee) :
<<<
macro			LOAD_QUAD		ofs, Ra, Rd		; load qword Rd depuis [Ra + imm]
>>>
A SUPPRIMER (a partir de la ligne qui suit l'ancre, jusqu'a "end macro" inclus) :
<<<
;			...............................
;	Choix automatique entre LDR (offset positif scale par 8, 0..32760)
;	ou LDUR (offset signe -256..255 non scale).
;	Pour les autres cas, materialisation dans x16.
  local signed_ofs
  signed_ofs = ofs							; Pour gerer le signe negatif
  local aTerm
  aTerm = Ra shl 5

  if ofs >= 0  &  ofs <= 32760  &  (ofs mod 8) = 0
    local imm12
    imm12 = ofs shr 3
    dd 0xF9400000  or  (imm12 shl 10)  or  aTerm or Rd			; ldr Rd, [Ra, #imm]

  else if ofs >= -256 & ofs <= 255
    dd 0xF8400000  or  ((signed_ofs and 0x1FF) shl 12)  or  aTerm or Rd	; ldur Rd, [Ra, #imm]

  else
    QUAD_CONST	17, signed_ofs
    dd 0xF8606800  or  (17 shl 16)  or  aTerm or Rd			; ldr Rd, [Ra, x17, lsl #0]
  end if
end macro
>>>

REMPLACEMENT :
<<<
;			...............................
;	Choix automatique entre LDR (offset positif scale par 8, 0..32760)
;	ou LDUR (offset signe -256..255 non scale) ; sinon materialisation dans x17.
;	Sans symbole local : ofs est substitue textuellement, d'ou (ofs) partout
;	(precedence fasmg : shr/and/mod lient plus fort que + - *).
  if (ofs) >= 0  &  (ofs) <= 32760  &  ((ofs) mod 8) = 0
    dd 0xF9400000  or  (((ofs) shr 3) shl 10)  or  (Ra shl 5)  or  Rd		; ldr Rd, [Ra, #ofs]
  else if (ofs) >= -256 & (ofs) <= 255
    dd 0xF8400000  or  (((ofs) and 0x1FF) shl 12)  or  (Ra shl 5)  or  Rd	; ldur Rd, [Ra, #ofs]
  else
    QUAD_CONST	17, (ofs)
    dd 0xF8606800  or  (17 shl 16)  or  (Ra shl 5)  or  Rd			; ldr Rd, [Ra, x17]
  end if
end macro
>>>

MODIF 2.15 -- LVA : (disp) parenthese (robustesse precedence)
---------------------------------------------------------------------
ANCRE (ligne existante unique, inchangee) :
<<<
macro			LVA	lvl:-1, disp:0			; Load Variable Address pour lvl et disp
>>>
A SUPPRIMER (a partir de la ligne qui suit l'ancre, jusqu'a "end macro" inclus) :
<<<
;			------------------------
;	Empile l'adresse de la variable au deplacement disp du frame de niveau lvl.
;	x86 : lea rax, [base + disp] ; ARM64 : add x0, base, #disp (immediat 12 bits ; sinon
;	via movz/movk + add).
  BASE_IN_RAX	lvl
  if disp = 0
;	x0 deja a la bonne valeur, rien a faire
  else if disp >= -4095 & disp <= 4095
    if disp >= 0
      dd 0x91000000 or (disp shl 10) or (0 shl 5) or 0			; add x0, x0, #disp
    else
      dd 0xD1000000 or ((-disp) shl 10) or (0 shl 5) or 0			; sub x0, x0, #(-disp)
    end if
  else
    QUAD_CONST	17, disp
    dd 0x8B110000							; add x0, x0, x17
  end if
  PUSH_RAX
end macro
>>>

REMPLACEMENT :
