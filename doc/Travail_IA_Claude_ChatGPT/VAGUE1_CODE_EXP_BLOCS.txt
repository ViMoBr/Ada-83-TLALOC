VAGUE 1 -- ARBRE DE CODE_EXP BRUYANT (expander-expressions.adb SEUL)
21 blocs. Contexte EXPRESSION, contrat +1 en pile : tout noeud avale
ici = n 115. Deux formes : COLLER APRES <ancre>, ou AVANT -> APRES.
Toutes les ancres sont UNIQUES dans le fichier (verifie le 28/07).
L'indentation des blocs est indicative : reprendre celle du site.

PROCEDURE DE DEPLOIEMENT (importante) :
  1. Coller, compiler.
  2. Run RECENSEMENT (option W) sur TOUT le corpus + auto-compilation.
     Des TROU peuvent crier sur du code aujourd'hui correct : un noeud
     legitimement silencieux que l'inventaire n'a pas prevu.
  3. Trier chaque cri : soit vrai trou (reste TROU), soit cas legitime
     -> promu en branche annotee INTENTIONNEL.
  4. Seulement alors, mode STRICT par defaut.
========================================================================

---[ D ]---------------------------------------------------------------
D. CODE_ATTRIBUTE (~l.2760-2905) -- 12 retouches. Message uniforme
   TROU( "CODE_ATTRIBUTE '..." ) : NODE_NAME ne donnerait que
   DN_ATTRIBUTE (constate a l'essai), c'est CHN_ATTR qui discrimine.
------------------------------------------------------------------------

D1. 'BASE : INTENTIONNEL.
AVANT :
    when  'B' => null;							-- BASE
APRES :
    when  'B' => null;	-- INTENTIONNEL : 'BASE = identite, la vue de
			-- base ne change pas la valeur deja empilee.

D2. Chaine 'C' (CALLABLE / CONSTRAINED / COUNT + else).
AVANT :
      if  CHN_ATTR( 2 ) = 'A'  then null;					-- CALLABLE
      elsif  CHN_ATTR( 2 .. 3 ) = "ON"  then CODE_CONSTRAINED;			-- CONSTRAINED
      elsif  CHN_ATTR( 2 .. 3 ) = "OU"  then null;				-- COUNT
      end if;
APRES :
      if  CHN_ATTR( 2 ) = 'A'  then TROU( "CODE_ATTRIBUTE 'CALLABLE (tasking)" );
      elsif  CHN_ATTR( 2 .. 3 ) = "ON"  then CODE_CONSTRAINED;			-- CONSTRAINED
      elsif  CHN_ATTR( 2 .. 3 ) = "OU"  then TROU( "CODE_ATTRIBUTE 'COUNT (tasking)" );
      else TROU( "CODE_ATTRIBUTE '" & CHN_ATTR );
      end if;

D3. 'LAST_BIT (dans la chaine 'L').
AVANT :
        else null;								-- LAST_BIT
APRES :
        else TROU( "CODE_ATTRIBUTE 'LAST_BIT (rep-clauses)" );

D4. Queue de la chaine 'L' (attribut en L non reconnu tombe au travers).
ANCRE :      elsif  CHN_ATTR( 2 .. 3 ) = "EN"  then CODE_LENGTH;
COLLER APRES (avant le end if; de la chaine, en sautant la ligne vide) :
      else TROU( "CODE_ATTRIBUTE '" & CHN_ATTR );

D5. Queue de la chaine 'M'.
ANCRE : la ligne portant				-- MACHINE_ROUNDS
COLLER APRES :
      else TROU( "CODE_ATTRIBUTE '" & CHN_ATTR );

D6. 'POSITION (dans la chaine 'P').

      if  CHN_ATTR'LENGTH = 8  then null;					-- POSITION
APRES :
      if  CHN_ATTR'LENGTH = 8  then TROU( "CODE_ATTRIBUTE 'POSITION (rep-clauses)" );

D7. Queue de la chaine 'P' (apres la branche PRED).
ANCRE :        PUT_LINE( tab & "DEC" );
