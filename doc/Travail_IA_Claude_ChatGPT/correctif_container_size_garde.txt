=======================================================================================================================
CORRECTIF PAS 4 — LECTURE GARDEE DE SM_SIZE (attribut CREUX sur DN_INTEGER)
=======================================================================================================================

Diagnostic : sur DN_INTEGER, l'emplacement SM_SIZE n'existe que si une clause
'SIZE a ete posee ; D( SM_SIZE, ... ) proteste sur les entiers de STANDRD.
Idiome maison a reprendre : REPRESENTED_RECORD_SIZE_BITS (represented_items,
~l.114) lit DI( SM_SIZE, TS ) sous "when others => 0".

Remplacer le bloc CONTAINER_SIZE entier par :

		CONTAINER_SIZE:
    declare
      SIZE_BITS		: INTEGER	:= DI( CD_IMPL_SIZE, INTEGER_SPEC );
      SIZE_CLAUSE	: INTEGER	:= 0;
      LST		: TREE		:= EXP_LST;
    begin
      begin
        SIZE_CLAUSE := DI( SM_SIZE, INTEGER_SPEC );				-- attribut creux : absent sur les types
      exception									-- sans clause (idiome represented_items)
        when others =>
	SIZE_CLAUSE := 0;
      end;

      if  SIZE_CLAUSE = 0  then
        begin
	SIZE_CLAUSE := DI( SM_SIZE, D( SM_BASE_TYPE, INTEGER_SPEC ) );
        exception
	when others =>
	  SIZE_CLAUSE := 0;
        end;
      end if;

      if  SIZE_CLAUSE > 0  then							-- 1. length clause : obeir (RM83 13.2)
        SIZE_BITS := SIZE_CLAUSE;

      elsif  IS_UNSIGNED_TYPE( INTEGER_SPEC )  then				-- 2. non signe : conteneur minimal non signe
        while  LST.TY = DN_PARENTHESIZED  or else  LST.TY = DN_CONVERSION  loop
	LST := D( AS_EXP, LST );
        end loop;
        if  LST.TY = DN_NUMERIC_LITERAL  then
	if    DI( SM_VALUE, LST ) <= 2**8  - 1  then  SIZE_BITS := 8;
	elsif DI( SM_VALUE, LST ) <= 2**16 - 1  then  SIZE_BITS := 16;
	end if;									-- au-dela : la taille signee du front-end
        end if;									-- donne deja le bon conteneur d/q
      end if;

      DI( CD_IMPL_SIZE, INTEGER_SPEC, SIZE_BITS );				-- 3. sinon : front-end inchange
      DI( CD_IMPL_SIZE, D( SM_BASE_TYPE, INTEGER_SPEC ), SIZE_BITS );
    end	CONTAINER_SIZE;

    SIZE_CHAR := OPER_SIZ_CHAR( INTEGER_SPEC );

NOTE : si le front-end pose la clause 'SIZE ailleurs que dans SM_SIZE pour les
entiers (a verifier au temoin : "for OCTET'SIZE use 8" doit donner LI 8 via la
branche 1 ; s'il donne LI 8 via la branche 2, la clause n'est pas lue mais le
resultat converge pour les non signes — seul un cas comme
"type I8 is range -128..127; for I8'SIZE use 8" departagera : il DOIT donner 8).
